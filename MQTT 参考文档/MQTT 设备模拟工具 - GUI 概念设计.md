# MQTT 设备模拟工具 - GUI 概念设计（可选扩展）

## 一、GUI 版本定位

GUI 版本作为命令行工具的补充，主要面向：
- **手动测试场景** - 测试人员快速发送测试消息
- **演示展示** - 向客户或领导展示系统功能
- **数据可视化** - 实时监控压力测试结果
- **配置管理** - 可视化配置 MQTT 连接和消息模板

---

## 二、技术选型建议

### 2.1 推荐方案：Electron + React

**优势**：
- ✅ 跨平台（Windows、Linux、macOS）
- ✅ 现代化的 UI 界面
- ✅ 丰富的图表库支持（ECharts、Chart.js）
- ✅ 与 Web 前端技术栈一致，便于维护

**技术栈**：
- 框架：Electron 28+
- UI 库：React 18 + Ant Design
- 图表：ECharts 5
- MQTT 库：mqtt.js
- 打包：electron-builder

### 2.2 备选方案：Python + PyQt5

**优势**：
- ✅ 与 CLI 版本共享核心代码
- ✅ 部署简单，无需打包
- ✅ 资源占用较低

**技术栈**：
- 框架：PyQt5 / PySide6
- 图表：PyQtGraph
- MQTT 库：paho-mqtt
- 样式：QSS

## 五、图表设计

### 5.1 吞吐量趋势图

- **图表类型**：折线图
- **X 轴**：时间（分钟）
- **Y 轴**：消息数/秒
- **颜色**：蓝色渐变
- **特性**：实时刷新（1 秒/次）

### 5.2 延迟分布图

- **图表类型**：直方图
- **X 轴**：延迟区间（ms）
- **Y 轴**：消息数量
- **颜色**：绿色（正常）、黄色（警告）、红色（危险）

### 5.3 成功率饼图

- **图表类型**：环形饼图
- **分区**：成功（绿色）、失败（红色）
- **中心**：显示总消息数

## 八、数据持久化

### 8.1 本地存储

- **配置文件**：JSON 格式，存储在 `%APPDATA%/mqtt-simulator/config/`
- **历史记录**：SQLite 数据库，存储在 `%APPDATA%/mqtt-simulator/data/`
- **日志文件**：文本格式，存储在 `%APPDATA%/mqtt-simulator/logs/`

### 8.2 数据导出
