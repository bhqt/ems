# MQTT 设备模拟工具 - UI 设计文档

## 一、界面设计概述

本工具提供两种交互方式：
1. **命令行界面（CLI）** - 主要交互方式，适合自动化测试
2. **图形界面（GUI）** - 辅助交互方式，适合手动测试和演示（可选扩展）

## 三、命令行参数设计

### 3.1 全局参数

```bash
mqtt_simulator.py [命令] [选项]

全局选项:
  --config, -c      配置文件路径 (默认：config/config.yaml)
  --log-level       日志级别 (DEBUG|INFO|WARNING|ERROR)
  --help, -h        显示帮助信息
  --version, -v     显示版本号
```

### 3.2 单消息发送命令

```bash
# 基本用法
mqtt_simulator.py send --topic <主题> --data <JSON 数据>

# 完整参数
mqtt_simulator.py send \
  --topic "electric/voltage" \
  --client-id "device_001" \
  --data '{"value": 220.5}' \
  --qos 0 \
  --retain \
  --dry-run  # 仅验证，不实际发送
```

**参数说明**：

| 参数 | 简写 | 说明 | 必填 | 默认值 |
|------|------|------|------|--------|
| `--topic` | `-t` | MQTT 主题 | 是 | - |
| `--client-id` | `-cid` | 设备 ID | 否 | auto |
| `--data` | `-d` | JSON 数据 | 是* | - |
| `--template` | `-tpl` | 使用模板 | 否* | - |
| `--qos` | `-q` | QoS 级别 (0-2) | 否 | 0 |
| `--retain` | `-r` | 保留消息 | 否 | false |
| `--dry-run` | `-n` | 空运行（不发送） | 否 | false |

### 3.3 压力测试命令

```bash
# 使用预设场景
mqtt_simulator.py stress --scenario light

# 自定义配置
mqtt_simulator.py stress \
  --devices 100 \
  --frequency 5 \
  --duration 300 \
  --message-type voltage \
  --output report.md
```

**参数说明**：

| 参数 | 简写 | 说明 | 必填 | 默认值 |
|------|------|------|------|--------|
| `--scenario` | `-s` | 测试场景 (light|medium|heavy) | 否* | light |
| `--devices` | `-d` | 设备数量 | 否* | 10 |
| `--frequency` | `-f` | 发送频率（消息/秒） | 否* | 1 |
| `--duration` | `-dur` | 持续时间（秒） | 否* | 60 |
| `--message-type` | `-mt` | 消息类型 | 否 | voltage |
| `--output` | `-o` | 输出报告文件 | 否 | auto |
| `--realtime` | `-rt` | 显示实时监控 | 否 | true |

### 3.4 其他命令

```bash
# 查看支持的主题
mqtt_simulator.py topics

# 查看消息模板
mqtt_simulator.py templates

# 验证配置
mqtt_simulator.py validate --config config.yaml

# 连接测试
mqtt_simulator.py ping
```
