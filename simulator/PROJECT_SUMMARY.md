## 一、项目背景

### 1.1 需求来源

祝融能源管理系统（Deep-EMS）需要一个 MQTT 设备模拟工具，用于：
- 测试 MQTT 消息链路是否打通
- 验证后端消息解析逻辑
- 进行系统性能压力测试
- 生成测试报告

### 1.2 设计目标

设计并实现一个功能完善的 MQTT 设备模拟工具，要求：
- 支持单条消息模拟和并发压力测试
- 符合后端消息解析逻辑
- 提供友好的命令行界面
- 生成专业的测试报告

## 七、使用指南

### 7.1 快速开始

**步骤 1: 安装依赖**
```bash
pip install -r requirements.txt
```

**步骤 2: 配置 MQTT 连接**
```yaml
# 编辑 config/config.yaml
mqtt:
  host: "tcp://192.168.1.100:1883"
  username: "admin"
  password: "public"
```

**步骤 3: 测试连接**
```bash
python main.py ping
```

**步骤 4: 发送消息**
```bash
# 发送电压数据
python main.py send -t electric/voltage -cid device_001 -tpl voltage
```

**步骤 5: 压力测试**
```bash
# 轻量测试
python main.py stress -s light
```
