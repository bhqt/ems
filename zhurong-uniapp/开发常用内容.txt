解构赋值语法
	// 使用了解构赋值语法，将 error 对象中的 message 属性提取出来并赋值给了一个名为 message 的变量。
	let { message } = error
	具体来说，这行代码等价于以下两行代码：
	// 方法一：使用点号访问属性
	let message = error.message;
	// 方法二：使用对象解构赋值语法
	let { message } = error;
	在 JavaScript 中，对象解构赋值语法可以帮助我们快速地从对象中提取需要的属性或方法，然后将它们赋值给变量。
	这种语法非常方便，尤其是在处理大型对象或多层嵌套的对象时，可以减少不必要的代码量。


前端向后端传递参数方式和后端接收方式
	第一种：/delete/{id}
		 前端传参：get、restful；后端接参：@GetMapping、@PathVariable
	第二种：/delete?id=11
		 前端传参：get、params；后端接参：@GetMapping、@RequestParam
	第三种：{id:1}
		 前端传参：post、data；后端接参：@PostMapping、@RequestBody
		 @RequestBody注解只能接收json对象的字符串，不能接收Json对象。如果前端传入的是Json对象，需要使用JSON.stringify(data)的方式将对象变成字符串，同时ajax请求也要指定dataType: “json”,contentType:“application/json”
		 前端传递json格式的参数{id:1}，后端方法 (@RequestBody String id)接收时，直接接收的整个json字符串，导致获取不到都应的参数值
		 public AjaxResult remove( @RequestBody String id)
		 可以修改为如下，通过map接收
		 public AjaxResult remove( @RequestBody Map<String,String> param)
			param.get("id")获取
