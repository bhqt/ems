## 步骤1：获取WSL的IP地址

打开WSL终端，执行以下命令：

```
ip addr show eth0 | grep inet | awk '{print $2}' | cut -d/ -f1
```

或者更简单：

```
hostname -I | awk '{print $1}'
```

假设获取到的WSL IP是 172.28.128.123

## 步骤2：修改后端接口地址

修改 .env.development 文件，将 localhost 替换为WSL的IP：

```
# 修改前
VUE_APP_BASE_API = 'http://localhost:8088/autoee-iot-ems'

# 修改后（请替换为你的WSL实际IP）
VUE_APP_BASE_API = 'http://172.28.128.123:8088/autoee-iot-ems'
```

## 步骤3：启动前端项目

```
# 进入项目目录
cd d:\code\gitcp\inspur-ems\deep-ems0\zhurong-admin-ui

# 安装依赖（如果还没安装）
npm install

# 启动开发服务器
npm run dev
```

## 注意事项

关于国际化语言头 ：
在 src/utils/request.js 第16行，有一个硬编码的语言头：

```
axios.defaults.headers['Content-Language'] = 'zh_CN'
```

如果需要根据用户选择的语言动态设置，可以修改为：

```
import i18n from '@/i18n'
axios.defaults.headers['Content-Language'] = i18n.locale.replace('-', '_')
```

WSL端口映射 ：
确保WSL的8088端口已经开放，并且后端服务正在运行。

跨域问题 ：
如果遇到跨域问题，请确保后端服务已配置CORS允许前端地址访问。

请先获取你的WSL IP地址，然后修改配置文件，最后启动项目。如果遇到任何问题，请告诉我！
