# 生产环境部署配置

## 服务器配置

### 硬件配置
- **CPU**：8核及以上
- **内存**：16GB及以上
- **磁盘**：200GB SSD
- **网络**：千兆网卡

### 软件配置
- **操作系统**：Windows Server 2019 64位
- **JDK**：Oracle JDK 1.8.0_202或更高版本
- **应用服务器**：Apache Tomcat 9.0.40或更高版本
- **数据库**：MySQL 8.0.23或更高版本
- **Redis**：Redis 6.0或更高版本（用于缓存）

## 环境变量配置

### Windows环境变量
1. **JAVA_HOME**：指向JDK安装目录
   ```
   JAVA_HOME=C:\Program Files\Java\jdk1.8.0_202
   ```

2. **PATH**：添加Java和Tomcat路径
   ```
   PATH=%JAVA_HOME%\bin;%CATALINA_HOME%\bin;%PATH%
   ```

3. **CATALINA_HOME**：指向Tomcat安装目录
   ```
   CATALINA_HOME=C:\apache-tomcat-9.0.40
   ```

## 数据库配置

### MySQL配置
1. **my.ini配置文件**
   ```ini
   [mysqld]
   port=3306
   basedir=C:/Program Files/MySQL/MySQL Server 8.0
   datadir=D:/MySQL/data
   max_connections=1000
   wait_timeout=28800
   interactive_timeout=28800
   innodb_buffer_pool_size=4G
   innodb_log_file_size=512M
   innodb_flush_log_at_trx_commit=2
   ```

2. **数据库创建**
   ```sql
   CREATE DATABASE ems_system CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
   ```

3. **用户创建**
   ```sql
   CREATE USER 'ems_user'@'localhost' IDENTIFIED BY 'StrongPassword123!';
   GRANT ALL PRIVILEGES ON ems_system.* TO 'ems_user'@'localhost';
   FLUSH PRIVILEGES;
   ```

4. **初始化数据**
   执行 `docs/sql/system_integration_init.sql` 脚本初始化数据库表结构

## Tomcat配置

### server.xml配置
```xml
<Server port="8005" shutdown="SHUTDOWN">
  <Service name="Catalina">
    <Connector port="8080" protocol="HTTP/1.1"
               connectionTimeout="20000"
               redirectPort="8443"
               maxThreads="500"
               minSpareThreads="100"
               maxSpareThreads="200"
               acceptCount="100"
               URIEncoding="UTF-8"/>
    <Connector port="8009" protocol="AJP/1.3" redirectPort="8443"/>
    <Engine name="Catalina" defaultHost="localhost">
      <Host name="localhost" appBase="webapps"
            unpackWARs="true" autoDeploy="true">
        <Valve className="org.apache.catalina.valves.AccessLogValve" directory="logs"
               prefix="access_log" suffix=".txt"
               pattern="%h %l %u %t &quot;%r&quot; %s %b &quot;%{Referer}i&quot; &quot;%{User-Agent}i&quot;" />
      </Host>
    </Engine>
  </Service>
</Server>
```

### catalina.bat配置
```bat
set JAVA_OPTS=-Xms4G -Xmx8G -XX:MetaspaceSize=512M -XX:MaxMetaspaceSize=1G -XX:+UseG1GC -XX:MaxGCPauseMillis=200 -XX:+ParallelRefProcEnabled -XX:+DisableExplicitGC -XX:+AlwaysPreTouch -XX:MaxInlineLevel=15
```

## 安全配置

### 防火墙配置
1. **入站规则**
   - 允许端口 8080（HTTP）
   - 允许端口 3306（MySQL）
   - 允许端口 6379（Redis）

2. **出站规则**
   - 允许访问外部系统API
   - 允许数据库连接

### SSL配置
1. **生成证书**
   ```
   keytool -genkey -alias ems -keyalg RSA -keystore ems.keystore -keysize 2048
   ```

2. **Tomcat SSL配置**
   ```xml
   <Connector port="8443" protocol="org.apache.coyote.http11.Http11NioProtocol"
              maxThreads="150" SSLEnabled="true">
     <SSLHostConfig>
       <Certificate certificateKeystoreFile="${CATALINA_HOME}/conf/ems.keystore"
                    certificateKeystorePassword="changeit"
                    type="RSA" />
     </SSLHostConfig>
   </Connector>
   ```

### 数据库安全
1. **密码策略**
   - 最小长度：8位
   - 包含大小写字母、数字和特殊字符
   - 定期更换密码

2. **权限控制**
   - 遵循最小权限原则
   - 生产环境使用只读账号进行查询操作
