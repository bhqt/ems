 
# 前后端容器分析与构建指南

## 1. 项目结构分析

### 1.1 前端项目
- **位置**：`zhurong-admin-ui/`
- **技术栈**：Vue.js 2.6.12 + Element UI 2.15.12
- **构建工具**：Vue CLI 4.4.6
- **容器化**：使用多阶段 Dockerfile 构建

### 1.2 后端项目
- **位置**：`zhurong-ems-admin/`（从构建脚本推断）
- **技术栈**：Java（从 pom.xml 推断）
- **构建工具**：Maven
- **容器化**：通过 build-docker.ps1 脚本构建

### 1.3 其他服务
- **XXL-Job**：任务调度服务
- **Monitor**：监控服务

## 2. 前端容器分析

### 2.1 Dockerfile 分析
- **多阶段构建**：
  1. **构建阶段**：使用 Node.js 20 镜像，安装依赖并构建生产版本
  2. **运行阶段**：使用 Nginx 1.28.3 镜像，提供静态文件服务
- **环境变量**：
  - `VUE_APP_BASE_API`：API 基础路径，默认 `/autoee-iot-ems/`
  - `VUE_APP_CONTEXT_PATH`：应用上下文路径，默认 `/`
  - `VUE_APP_TITLE`：应用标题，默认 "智碳能源管理系统"
- **构建产物**：复制到 Nginx 的 `/usr/share/nginx/html` 目录
- **Nginx 配置**：使用自定义配置文件，包含反向代理设置

### 2.2 构建流程
1. 安装依赖：`npm install --legacy-peer-deps`
2. 构建生产版本：`NODE_OPTIONS=--openssl-legacy-provider npm run build:prod`
3. 复制构建产物到 Nginx 容器
4. 启动 Nginx 服务

## 3. 后端容器分析

### 3.1 构建流程
- 通过 `build-docker.ps1` 脚本构建
- 使用 Dockerfile 构建后端镜像
- 镜像标签：`zhurong-ems/backend:latest`

### 3.2 依赖管理
- 使用 Maven 管理依赖
- 根目录有 `pom.xml` 文件，用于构建整个项目

## 4. 编译、打包、生成 Docker Image 步骤

### 4.1 前端构建步骤

1. **进入前端目录**
   ```powershell
   cd zhurong-admin-ui
   ```

2. **安装依赖**
   ```powershell
   npm config set registry https://registry.npmmirror.com
   npm install --legacy-peer-deps
   ```

3. **构建生产版本**
   ```powershell
   NODE_OPTIONS=--openssl-legacy-provider npm run build:prod
   ```

4. **构建 Docker 镜像**
   ```powershell
   docker build -t zhurong-ems/frontend:latest .
   ```

### 4.2 后端构建步骤

1. **进入后端目录**
   ```powershell
   cd zhurong-ems-admin
   ```

2. **构建后端项目**
   ```powershell
   mvn clean package -DskipTests
   ```

3. **构建 Docker 镜像**
   ```powershell
   docker build -t zhurong-ems/backend:latest .
   ```

### 4.3 使用构建脚本构建所有服务

1. **构建所有服务**
   ```powershell
   .\build-docker.ps1 -All
   ```

2. **只构建前端**
   ```powershell
   .\build-docker.ps1 -Frontend
   ```

3. **只构建后端**
   ```powershell
   .\build-docker.ps1 -Backend
   ```

4. **清理构建缓存**
   ```powershell
   .\build-docker.ps1 -Clean
   ```

## 5. 容器编排

### 5.1 Docker Compose 配置
- 根目录有 `docker-compose.yml` 文件
- 支持多服务编排，包括前端、后端、数据库等

### 5.2 启动服务
```powershell
docker-compose up -d
```

### 5.3 停止服务
```powershell
docker-compose down
```

## 6. 技术亮点与优化建议

### 6.1 技术亮点
- **多阶段构建**：前端使用多阶段构建，减小最终镜像体积
- **环境变量配置**：支持通过构建参数自定义 API 路径等配置
- **自动化构建**：提供了完整的 PowerShell 构建脚本
- **模块化设计**：将不同服务分离为独立模块

### 6.2 优化建议
1. **前端优化**：
   - 考虑使用 Vite 替代 Vue CLI，提高构建速度
   - 增加代码分割，进一步优化加载性能
   - 添加前端测试，确保构建质量

2. **后端优化**：
   - 考虑使用分层构建，减小后端镜像体积
   - 添加健康检查和优雅启动/停止机制
   - 优化数据库连接和缓存策略

3. **构建流程优化**：
   - 集成 CI/CD 流程，实现自动化构建和部署
   - 添加构建缓存，提高构建速度
   - 实现镜像版本管理，便于回滚和部署

## 7. 总结

本项目采用了现代化的容器化部署方案，前端使用 Vue.js + Nginx，后端使用 Java 技术栈，通过 Docker 容器实现了服务的隔离和标准化部署。构建脚本 `build-docker.ps1` 提供了便捷的构建工具，支持单独构建各个服务或构建所有服务。

通过以上步骤，可以成功编译、打包并生成 Docker 镜像，为项目的部署和运行提供了可靠的基础。

# 把 WSL 里的两个 Docker 镜像导出到 D 盘 .tar 格式
我直接给你**一步到位、可直接复制运行**的完整命令，无需额外操作。

## 1. 导出 backend 镜像
```bash
docker save -o /mnt/d/zhurong-ems-backend.tar zhurong-ems/backend:latest
```

## 2. 导出 frontend 镜像
```bash
docker save -o /mnt/d/zhurong-ems-frontend.tar zhurong-ems/frontend:latest
```

---

# 说明（非常简单）
- **WSL 访问 D 盘** 路径就是：`/mnt/d/`
- 导出后文件会直接出现在 **D 盘根目录**
- 文件名我已经帮你起好，清晰好认：
  - `zhurong-ems-backend.tar`
  - `zhurong-ems-frontend.tar`

---

# 如果你想**压缩成 .tar.gz**（更小）
用这两条命令：
```bash
docker save zhurong-ems/backend:latest | gzip > /mnt/d/zhurong-ems-backend.tar.gz
```

```bash
docker save zhurong-ems/frontend:latest | gzip > /mnt/d/zhurong-ems-frontend.tar.gz
```

---

### 总结
1. 直接复制上面两条命令到 WSL 运行即可
2. 导出完成后去 **D 盘** 就能看到 `.tar` 镜像文件
3. 体积和你看到的一致：后端 ~516MB，前端 ~148MB
