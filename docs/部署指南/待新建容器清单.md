## 八、Docker Compose 配置（接入现有网络）

> 补充：Docker Compose 配置，加入 `legal-network` 网络与现有系统互联

```yaml
version: '3.8'

# Deep-EMS 新增中间件服务
# 加入 legal-network 与现有系统互联

services:
  # RabbitMQ 消息队列
  zhurong-ems-rabbitmq:
    image: rabbitmq:3.12-management-alpine
    container_name: zhurong-ems-rabbitmq
    restart: unless-stopped
    environment:
      RABBITMQ_DEFAULT_USER: zhurong
      RABBITMQ_DEFAULT_PASS: zhurong123
      TZ: Asia/Shanghai
    ports:
      - "5672:5672"
      - "15672:15672"
    volumes:
      - zhurong-ems-rabbitmq-data:/var/lib/rabbitmq
    networks:
      - legal-network
    healthcheck:
      test: ["CMD", "rabbitmq-diagnostics", "ping"]
      interval: 10s
      timeout: 5s
      retries: 5

  # EMQX MQTT 消息代理
  zhurong-ems-emqx:
    image: emqx/emqx:5.3.0
    container_name: zhurong-ems-emqx
    restart: unless-stopped
    environment:
      EMQX_NAME: zhurong-ems-emqx
      EMQX_HOST: 127.0.0.1
      EMQX_DASHBOARD__DEFAULT_USERNAME: admin
      EMQX_DASHBOARD__DEFAULT_PASSWORD: public
      TZ: Asia/Shanghai
    ports:
      - "1883:1883"
      - "8083:8083"
      - "18083:18083"
    volumes:
      - zhurong-ems-emqx-data:/opt/emqx/data
      - zhurong-ems-emqx-log:/opt/emqx/log
    networks:
      - legal-network
    healthcheck:
      test: ["CMD", "emqx", "ctl", "status"]
      interval: 10s
      timeout: 5s
      retries: 5

  # XXL-Job 执行器
  zhurong-ems-xxl-job:
    image: xuxueli/xxl-job-core:2.3.1
    container_name: zhurong-ems-xxl-job
    restart: unless-stopped
    environment:
      PARAMS: >
        --spring.datasource.url=jdbc:mysql://legal-mysql:3306/xxl_job?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
        --spring.datasource.username=root
        --spring.datasource.password=root
        --spring.datasource.driver-class-name=com.mysql.cj.jdbc.Driver
        --xxl.job.admin.addresses=http://zhurong-ems-xxl-job-admin:8080/xxl-job-admin
        --xxl.job.accessToken=default_token
        --xxl.job.executor.appname=zhurong-ems-executor
        --xxl.job.executor.port=9101
    ports:
      - "9101:9101"
    networks:
      - legal-network
    depends_on:
      - legal-mysql

  # XXL-Job 调度中心（可选，独立部署）
  # 如不需要可注释掉
  # zhurong-ems-xxl-job-admin:
  #   image: xuxueli/xxl-job-admin:2.3.1
  #   container_name: zhurong-ems-xxl-job-admin
  #   restart: unless-stopped
  #   environment:
  #     SPRING_DATASOURCE_URL: jdbc:mysql://legal-mysql:3306/xxl_job?useUnicode=true&characterEncoding=UTF-8&serverTimezone=Asia/Shanghai
  #     SPRING_DATASOURCE_USERNAME: root
  #     SPRING_DATASOURCE_PASSWORD: root
  #     SPRING_PROFILES_ACTIVE: admin
  #     TZ: Asia/Shanghai
  #   ports:
  #     - "9100:8080"
  #   networks:
  #     - legal-network
  #   depends_on:
  #     - legal-mysql

  # Spring Boot Admin 监控
  zhurong-ems-sba:
    image: codecentric/spring-boot-admin:2.7.10
    container_name: zhurong-ems-sba
    restart: unless-stopped
    environment:
      SPRING_PROFILES_ACTIVE: admin
      SPRING_BOOT_ADMIN_ADMIN_USERNAME: admin
      SPRING_BOOT_ADMIN_ADMIN_PASSWORD: zhurong123
      TZ: Asia/Shanghai
    ports:
      - "9090:9090"
    networks:
      - legal-network

  # TDengine 时序数据库（可选）
  zhurong-ems-tdengine:
    image: tdengine/tdengine:3.2.0.0
    container_name: zhurong-ems-tdengine
    restart: unless-stopped
    environment:
      TAOS_FQDN: zhurong-ems-tdengine
      TZ: Asia/Shanghai
    ports:
      - "6030:6030"
      - "6041:6041"
    volumes:
      - zhurong-ems-tdengine-data:/var/lib/taos
      - zhurong-ems-tdengine-log:/var/log/taos
    networks:
      - legal-network
    privileged: true
    healthcheck:
      test: ["CMD", "taos", "-s", "SELECT 1"]
      interval: 10s
      timeout: 5s
      retries: 5

# 数据卷
volumes:
  zhurong-ems-rabbitmq-data:
    driver: local
  zhurong-ems-emqx-data:
    driver: local
  zhurong-ems-emqx-log:
    driver: local
  zhurong-ems-tdengine-data:
    driver: local
  zhurong-ems-tdengine-log:
    driver: local

# 网络 - 必须与现有系统一致
networks:
  legal-network:
    driver: bridge
    name: legal-network
  ssrf_proxy_network:
    driver: bridge
    internal: true
```

### 使用说明

1. **RabbitMQ**
   - 服务名：`zhurong-ems-rabbitmq`
   - AMQP端口：5672
   - 管理界面：http://localhost:15672
   - 用户名/密码：`zhurong / zhurong123`

2. **EMQX**
   - 服务名：`zhurong-ems-emqx`
   - MQTT端口：1883
   - WebSocket端口：8083
   - Dashboard：http://localhost:18083
   - 用户名/密码：`admin / public`

3. **XXL-Job**
   - 服务名：`zhurong-ems-xxl-job`
   - 端口：9101
   - 需提前在 `legal-mysql` 中创建 `xxl_job` 数据库

4. **Spring Boot Admin**
   - 服务名：`zhurong-ems-sba`
   - 端口：9090
   - 用户名/密码：`admin / zhurong123`

5. **TDengine**（可选）
   - 服务名：`zhurong-ems-tdengine`
   - 原生端口：6030
   - RESTful端口：6041

### 部署命令

```bash
# 启动所有新增服务
docker-compose -f docker-compose-zhurong-ems.yml up -d

# 查看日志
docker-compose -f docker-compose-zhurong-ems.yml logs -f

# 停止服务
docker-compose -f docker-compose-zhurong-ems.yml down
```

### 业务容器连接配置示例

业务容器（如 `legal-backend`）连接新增服务时的配置：

```yaml
# RabbitMQ 连接
SPRING_RABBITMQ_HOST: zhurong-ems-rabbitmq
SPRING_RABBITMQ_PORT: 5672
SPRING_RABBITMQ_USERNAME: zhurong
SPRING_RABBITMQ_PASSWORD: zhurong123

# EMQX (MQTT) 连接
MQTT_HOST: zhurong-ems-emqx
MQTT_PORT: 1883

# Redis 复用已有
SPRING_REDIS_HOST: shared-redis
SPRING_REDIS_PORT: 6379

# MySQL 复用已有
SPRING_DATASOURCE_URL: jdbc:mysql://legal-mysql:3306/
```
