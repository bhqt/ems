## 1. 关于本手册

### 1.1 这本手册能帮你做什么

本手册面向**每天使用系统干活的业务用户**，教你怎么登录、怎么查数、怎么录单据、怎么处理报警、怎么出报表、怎么用手机巡检。系统管理类操作（建账号、配权限、接设备、改参数）请看《06-03 系统管理员手册》。

### 1.2 怎么读这本手册最快

1. 第一次用系统：从[第 3 章 快速开始](#3-快速开始)读起，30 分钟可以上手。
2. 只学自己岗位：直接翻[第 4 章 分角色导览](#4-分角色导览)，按图索骥。
3. 遇到问题：先查[第 18 章 FAQ](#18-常见问题-faq)，解决不了再联系系统管理员。

### 1.3 操作步骤中的约定

| 约定 | 含义 |
| --- | --- |
| **菜单：A → B → C** | 在左侧菜单依次点击 A、B、C 进入对应页面 |
| 【按钮名】 | 页面上的按钮，如【新增】【导出】 |
| "字段名" | 表单或表格中的字段 |
| ⚠️ | 容易出错或需要特别注意的事项 |
| 💡 | 实用小技巧 |
| 📷 截图占位 | 正式版放截图的位置 |

## 2. 术语速查

| 术语 | 通俗解释 |
| --- | --- |
| EMS | 能源管理系统，本平台的统称 |
| 院区 | 医院的一个地理院区，医院数据按院区互相隔离 |
| 网关 | 把现场设备数据采集上来、转发到平台的装置 |
| 表计 | 电表、水表、气表等计量仪表 |

| 越限 | 实时值超过报警规则设定的上限或下限 |
| 工单 | 维修/巡检任务单据，可由报警自动生成或人工新建 |

## 3. 快速开始

### 3.1 浏览器要求

| 项目 | 要求 |
| --- | --- |
| 推荐浏览器 | Google Chrome 114 及以上 |
| 也支持 | Microsoft Edge 114 及以上 |
| 不支持 | Internet Explorer（IE）、360 兼容模式、过老版本国产浏览器 |
| 屏幕分辨率 | 建议 1920×1080；笔记本 1366×768 也可使用 |
| 其他 | 关闭广告拦截插件；允许本网站弹窗（导出时需要） |

系统访问地址：

- 开发/培训环境：`http://localhost:9029`（由实施方提供实际地址）
- 生产环境：由医院信息科或实施方通过 Nginx 发布的正式地址（通常为 https 地址）
- 后端服务统一挂在 `/autoee-iot-ems` 路径下，你不需要直接访问它。

### 3.2 登录系统

1. 打开浏览器，在地址栏输入系统地址，按回车，进入登录页。
2. 输入"用户名"和"密码"（初始账号由管理员提供，默认管理员为 `admin` / `123456`，**首次登录必须修改**）。
3. 如页面显示"验证码"，按图片输入验证码（看不清可点击图片换一张）。
4. 勾选"记住我"可在本机保留登录状态（公共电脑不要勾）。
5. 点击【登录】进入系统首页。

> 📷 截图占位：登录页整体截图，标注用户名、密码、验证码、语言切换、登录按钮。

⚠️ 注意：

- 连续输错密码会触发账号锁定，等待锁定超时或联系管理员重置。
- 培训请使用培训环境地址和 `stu_` 开头的学员账号，不要进生产环境练习。

### 3.3 忘记密码怎么办

1. 在登录页点击【忘记密码/找回密码】（如管理员已开放该功能）。
2. 按提示输入用户名与注册手机号，通过短信验证码重置。
3. 若该入口不可用或手机号已变更，直接联系系统管理员在"系统管理 → 用户"中重置密码（详见管理员手册）。

### 3.4 认识首页布局

登录后看到的界面分为五个区域：

| 区域 | 位置 | 作用 |
| --- | --- | --- |
| 顶部导航栏 | 最上方 | Logo、系统名称、语言切换、消息通知、全屏、个人头像菜单 |
| 左侧菜单栏 | 左侧 | 按业务分组的功能菜单，点小箭头展开/收起 |
| 标签页栏 | 菜单右侧上方 | 已打开页面的页签，可多页切换、点 × 关闭、刷新当前页 |
| 工作区 | 中间最大区域 | 看板、列表、表单等实际内容 |
| 底部/收起栏 | 边缘 | 版权信息、菜单折叠按钮 |

> 📷 截图占位：首页全貌，用红色编号标出五个区域。

首页"数据看板"通常展示：今日/本月总能耗、同比环比、各能源种类占比、实时功率曲线、最新报警、设备在线率、定额执行情况、充电运营概况等卡片。点击卡片或图表上的数字，多数可以**钻取**到明细页面。

### 3.5 语言切换（中/英/俄/印尼）

1. 看页面右上角，找到语言图标（地球/旗帜样式）或语言名称。
2. 点击后在下拉列表中选择：**简体中文 / English / Русский / Bahasa Indonesia**。
3. 界面菜单立即切换为所选语言，无需重新登录。
4. 医院项目日常使用中文；涉外交流或外宾参观时可切 English。

> 📷 截图占位：语言下拉菜单四种语言。

💡 语言切换只影响界面显示，不影响数据；你录入的中文内容不会被翻译。

### 3.6 修改个人资料与密码

1. 点击右上角头像，选择【个人中心】。
2. **改资料**：可修改昵称、手机号、邮箱、性别等，改完点【保存】。
3. **改密码**：点【修改密码】，依次输入"旧密码、新密码、确认密码"后保存。
4. 新密码要求：通常不少于 8 位，包含字母和数字；不要与用户名相同，不要继续使用初始密码。
5. 修改成功后需用新密码重新登录。

> 📷 截图占位：个人中心资料页与修改密码弹窗。

### 3.7 通用操作范式（所有列表页都一样）

学会这一节，80% 的页面你都会用。

#### 3.7.1 查询与筛选

1. 进入任意列表页，顶部是"查询条件区"。
2. 在下拉框/日期框中选择条件，例如时间范围、院区、设备类型、状态。
3. 点击【搜索/查询】刷新结果；点击【重置】清空所有条件。
4. 时间范围支持快捷项（今天、近 7 天、本月、本年），也可自定义起止日期。

#### 3.7.2 分页与排序

1. 表格底部显示总条数与分页按钮。
2. 可调整每页条数（10/20/50/100）。
3. 点击带小箭头的列标题可按该列升/降序排列。

#### 3.7.3 新增、编辑、删除

1. **新增**：点左上角【新增】，弹出表单，带红色 `*` 的为必填项，填写后点【确定】。
2. **编辑**：在该行点【修改/编辑】图标（铅笔样式），改完保存。
3. **删除**：勾选一行或多行前的复选框，点【删除】；或在该行点删除图标（垃圾桶样式）。系统会再次确认。
4. ⚠️ 删除多为逻辑删除（数据标记为删除不可见），但**不要随意删除业务单据**，删除后可能影响统计；不确定就停用而不是删除。

#### 3.7.4 Excel 导入

1. 在列表页点【导入】，弹窗中点【下载模板】。
2. 在下载的 Excel 模板里按列填写（不要改表头、不要加合计行；字典类字段按提示填，如状态填"正常"而不是"1"）。
3. 保存后在弹窗中选择文件，点【上传】。
4. 系统校验后提示成功条数、失败条数；**失败的要下载错误报告，按原因改完重新导入**。

#### 3.7.5 Excel 导出

1. 先用查询条件筛选出你要的数据（导出的是当前筛选结果）。
2. 点【导出】，浏览器开始下载 `.xlsx` 文件。
3. 如浏览器拦截下载，在地址栏右侧"允许弹出窗口"后重试。
4. ⚠️ 导出受权限控制，看不到【导出】按钮说明没有导出权限；数据量大时请缩小时间范围分批导出。

#### 3.7.6 图表交互

1. **时间粒度**：图表上方可切换 时/日/月/年。
2. **图例**：点击图例中的某一项可隐藏/显示该曲线。
3. **缩放**：在曲线上按住鼠标拖选一段时间可放大查看，双击复位（不同图表以页面提示为准）。
4. **看数值**：鼠标悬停在曲线上显示该点具体数值。
5. **下载图表**：部分图表右上角有下载图标，可存为图片用于汇报。

> 📷 截图占位：一张列表页组合截图，标注查询区、新增/导入/导出按钮、复选框、行内操作图标、分页。

## 5. 设备管理

设备数据来自两条链路：现场设备经 **MQTT 直采**（设备 → EMQX → RabbitMQ → MySQL/TDengine），或由**外部 IOT 平台 HTTP 回调**推送。业务用户主要在页面维护档案、查看状态。

### 5.1 设备信息

**功能简介**：建立全院/园区的设备台账，记录设备名称、编码、类型、所属院区/部门、位置、绑定网关与采集点、投运日期等，并查看在线/运行状态。

**菜单路径**：**设备管理 → 设备信息**

**操作步骤**：

1. 进入页面，顶部可按"院区、设备类型、运行状态、关键字"筛选。
2. 新增：点【新增】，在弹窗中填写：
   - "设备名称"（如：门诊CT-01）、"设备编码"（建议与现场铭牌一致，全局唯一）；
   - "设备类型"（下拉字典选择）、"所属院区/部门"、"安装位置"；
   - "关联网关"（从已建档网关中选择）、"投运日期"、"生产厂家"、"额定功率"等。
3. 点【确定】保存；批量建档用【导入】，先下载模板。
4. 在列表中查看"在线状态"（在线/离线）、"运行状态"（医院设备为在线/运行/待机/故障）、"实时功率""累计电量"。
5. 点行内【详情】可查看该设备的实时数据与历史曲线。

> 📷 截图占位：设备信息列表与新增弹窗。

**字段说明（常用）**：

| 字段 | 说明 |
| --- | --- |
| 设备编码 | 与采集/IOT 映射对应的唯一编号，**录错会导致数据上不来**，录后尽量不改 |
| 所属院区 | 决定数据隔离范围，跨院区看不到的首要排查项 |
| 运行状态 | 由实时数据自动计算，一般不由人工修改 |
| 关联网关/IOT 设备 | 设备与采集通道的绑定关系，由 IOT 运维维护 |

**注意事项**：

- ⚠️ 设备编码必须与网关/IOT 平台侧的映射一致，新增设备后若长期无数据，联系 IOT 运维检查绑定与回调日志。
- 设备停用建议改"状态=停用"，不要删除，以保留历史能耗归属。

### 5.2 网关

**功能简介**：维护采集网关档案及其与平台的连接状态。

**菜单路径**：**设备管理 → 网关**

**操作步骤**：

1. 点【新增】，填写"网关名称、网关编号、型号、所属院区、安装位置、通信方式（MQTT 等）"。
2. 保存后在列表查看"在线状态""最后心跳时间"。
3. 网关超过设定时间无心跳会显示离线；离线后其下挂设备数据都会中断，应立即报修。

> 📷 截图占位：网关列表，标注在线状态与最后心跳时间。

## 6. 能耗分析

能耗分析是能源负责人的主战场，共九类分析加费用报表。各图表操作方式一致：**选条件（时间、院区、分项、对象）→ 看图表/表格 → 导出或下钻**。

**菜单路径**：**能耗分析 → （能耗概况 / 趋势分析 / 同比环比 / 分项能耗 / 能源流向 / 损耗分析 / 费用报表 / 能源平衡 / 电能质量）**

### 6.1 能耗概况

**功能简介**：一屏掌握总用量、各能源种类（电/水/气等）用量、实时功率、当日/当月累计与同比环比。

**操作步骤**：

1. 进入 **能耗分析 → 能耗概况**。
2. 在顶部选择"院区"和"时间"。
3. 查看指标卡（总电量、总费用、同比、环比）与饼图（能源种类占比）。
4. 点击任一指标卡进入对应明细。

### 6.2 趋势分析

**功能简介**：查看能耗随时间变化曲线，支持按时/日/月/年粒度。

**操作步骤**：选"院区 + 计量点/设备 + 时间范围 + 粒度"→【查询】→ 可切换折线/柱状图、导出 Excel 或图片。

### 6.3 同比环比

1. 选择对象与时间周期（如 2026 年 8 月）。
2. 页面同时给出：本期值、环比上期值与增减幅、同比去年同期值与增减幅。
3. 增幅异常（红色）的行可点入趋势图核实是否为产量/天气/设备故障原因。

### 6.4 分项能耗

**功能简介**：按照明、空调、动力、医疗设备、特殊用电等分项统计。

**操作步骤**：选院区与时间 → 查看分项堆叠柱状图与占比饼图 → 导出用于节能分析。

### 6.5 能源流向（桑基图）

**功能简介**：以桑基/流向图展示能源从进线总表到各分项、各区域的流向与大小。

**操作步骤**：选择院区与时间 → 鼠标悬停某条"流"可看数值；用于识别大用户与损耗环节。

### 6.6 损耗分析

**功能简介**：对比总表与各分表之和，计算线损/管损及损耗率。

**操作步骤**：选择"总表 + 分表组 + 时间"→ 查看损耗量、损耗率曲线与超标记录。损耗率持续偏高时：先排查分表是否漏计/故障，再排查跑冒滴漏与偷接。

### 6.7 费用报表（重点）

**功能简介**：按电价（支持分时电价）/水价/气价计算能源费用，按月出具费用报表，是月度汇报必备。

**菜单路径**：**能耗分析 → 费用报表**

**操作步骤**：

1. 选择"院区、月份、费用对象（全院/科室/分项）"。
2. 点【计算/查询】，表格列出用电量、峰平谷电量、单价、金额、同比环比金额。
3. 核对无误后点【导出】得到 Excel，可直接贴入月度报告。
4. 电价或用量异常的单元格标红，点该单元格可下钻到日数据。

> 📷 截图占位：费用报表明细与导出按钮。

### 6.8 能源平衡

**功能简介**：按能源平衡表格式展示购入、转换、分配、消耗的平衡关系。选择时间后查看平衡表，差异率应在允许范围内；差异过大说明计量点缺失或表计异常。

### 6.9 电能质量

**功能简介**：查看电压、电流、功率因数、谐波、三相不平衡等电能质量指标越限情况。

**操作步骤**：选监测点与时间 → 查看曲线与越限记录 → 对频繁越限点生成隐患记录，必要时转维修工单。

> 📷 截图占位：能耗分析模块九张图拼图，统一标注查询条件区与导出按钮位置。

**注意事项**：

- 所有统计均依赖表计与采集数据，**图上没数先看设备/网关是否在线**，而不是反复点查询。
- 导出的数字以你筛选的条件为准，汇报时注明院区与时间口径。

## 7. 报警管理

报警链路：实时数据越限 → 系统按"报警规则"自动生成报警 → 在实时报警中展示，并可按配置**发邮件通知、自动生成维修工单**；处理完成后进入历史报警。

### 7.1 实时报警

**功能简介**：展示尚未闭环的当前报警，按级别（紧急/重要/一般）颜色区分。

**菜单路径**：**报警管理 → 实时报警**

**处理步骤**：

1. 打开页面，按"院区、级别、设备、时间"筛选；红色置顶为紧急报警。
2. 选中一条报警，点【详情】查看：报警对象、报警项、阈值、实时值、触发时间。
3. **核实**：通过设备实时监测/视频/电话确认是否真实异常。
4. 点【确认/接警】，填写确认人与初步判断。
5. 需维修时：
   - 若规则已开启"自动生成工单"，在弹窗中可看到已生成的工单号，点号跳转；
   - 否则点【生成工单】，选择维修班组与优先级。
6. 处理完毕、值恢复正常后，点【消警/闭环】，填写处理结果，报警转入历史报警。

> 📷 截图占位：实时报警列表 → 详情 → 确认/派单三连操作截图。

### 7.2 历史报警

**菜单路径**：**报警管理 → 历史报警**

1. 按时间/院区/设备/级别/处理状态查询已闭环（或已结束）报警。
2. 用于追溯、统计报警频次、导出月度报警台账。
3. 高频报警设备应列入重点检修或更换计划。

### 7.3 报警规则（查看）

**菜单路径**：**报警管理 → 报警规则**

- 业务用户可查看规则（阈值、级别、通知人、是否联动工单/邮件）；
- 修改阈值、通知人等配置一般由管理员/能源负责人操作，见《06-03 系统管理员手册》第 7 章。
- 💡 报警过多造成刷屏时，不要无视，应提交"调整阈值/增加延时判定"的申请。

**处置时限建议**：

| 级别 | 响应时限 | 处置要求 |
| --- | --- | --- |
| 紧急 | 10 分钟内接警 | 立即核实，必要时到场，同步值班长 |
| 重要 | 30 分钟内 | 当班核实并派单，当日闭环或说明 |
| 一般 | 当班内 | 登记并纳入计划检修 |

## 8. 运维管理

涵盖巡检计划/记录/巡检点/路径/任务、维修工单、值班、排班、示例报告。

**菜单路径**：**运维管理 → （巡检计划 / 巡检记录 / 巡检点 / 巡检路径 / 巡检任务 / 维修工单 / 值班 / 排班 / 示例报告）**

### 8.1 巡检点、巡检路径

1. **巡检点**：在"巡检点"中点【新增】，填写点名称、所属位置、关联设备、巡检项（如温度、声音、表读数）、是否需要扫码/NFC。
2. **巡检路径**：在"巡检路径"中点【新增】，填写路径名称，按行走顺序勾选巡检点并保存。

### 8.2 巡检计划与任务

1. 进入 **运维管理 → 巡检计划**，点【新增】。
2. 选择"巡检路径、责任人/班组、周期（每日/每周/自定义 cron 式周期）、起止日期、提醒方式"。
3. 保存后系统按计划自动生成"巡检任务"，并推送到责任人的移动端 APP。
4. 在"巡检任务"中可查看每个任务状态（待执行/执行中/已完成/超时）。

### 8.3 巡检执行与记录

**PC 端查看路径**：**运维管理 → 巡检记录**

1. 每条记录显示：任务、巡检人、开始/完成时间、巡检点结果、现场照片、异常项。
2. 发现异常的巡检项会被标记，可一键【转工单】。
3. 现场执行动作（接单、扫码/打卡、拍照、填报）主要在手机 APP 上完成，见[第 17 章](#17-移动端-app-使用)。

### 8.4 维修工单

**功能简介**：工单全生命周期管理：新建/报警转入 → 派单 → 接单 → 到场 → 处理（备件、照片）→ 验收 → 归档。

**菜单路径**：**运维管理 → 维修工单**

**操作步骤（派单方/班组长）**：

1. 点【新增】或从报警/巡检异常转入，填写：设备、故障现象、优先级、要求完成时间、指派维修人。
2. 在列表跟踪状态：待派单 → 待接单 → 处理中 → 待验收 → 已完成。
3. 维修人在移动端接单并回填处理过程、备件消耗、停机时长、照片。
4. 完工后由派单方/设备责任人点【验收】，不合格可【退回】重处理。
5. 【导出】可输出维修台账，用于 MTTR（平均修复时间）等统计。

> 📷 截图占位：工单详情页时间轴（派单/接单/到场/完成/验收各节点）。

### 8.5 值班与排班

1. **排班**：在"排班"中设置班次（如白班/夜班）、班组与人员轮班规则，生成月度排班表。
2. **值班**：值班人员在"值班"中签到、查看本班报警与工单、填写值班日志与交接班记录。
3. 排班决定了报警通知在什么时间推送给谁，请保持排班表最新。

### 8.6 示例报告

**功能简介**：系统内置巡检/运行示例报告模板，可查看报告样式，理解一次完整巡检应留下哪些记录与结论。

## 9. 物品管理

涵盖物品/危化品信息、库存、入库、出库、供应商、合同、附件。

**菜单路径**：**物品管理 → （物品信息 / 危化品信息 / 库存 / 入库 / 出库 / 供应商 / 合同 / 附件）**

### 9.1 物品档案

1. 进入"物品信息"，点【新增】：名称、编码、分类、规格型号、计量单位、安全库存（下限）、上限、存放库房/货位。
2. 危化品另在"危化品信息"中登记：CAS 号、危险类别、MSDS 附件、双人双锁等管控要求。
3. 支持 Excel 批量导入。

### 9.2 入库

1. 进入 **物品管理 → 入库**，点【新增入库单】。
2. 选择供应商与合同（可选），在明细中添加物品、数量、单价、批号、生产日期/有效期。
3. 保存并【审核】后，库存自动增加；未审核单据不影响库存。
4. 可上传送货单、质检单等附件。

### 9.3 出库

1. 进入"出库"，点【新增出库单】。
2. 选择"领用科室/领用人、用途"，添加物品与数量（系统自动扣减对应批次库存）。
3. 审核后库存减少；危化品出库需符合管控要求并登记使用与余量。

### 9.4 库存与预警

1. **物品管理 → 库存**：实时查看各物品当前库存、占用、可用量、库位。
2. 库存**低于下限**或超过上限、危化品**临近有效期**时列表标红并提示预警。
3. 定期用【库存盘点】功能生成盘点单，录入实盘数，处理盘盈盘亏。
4. "供应商""合同"分别维护供方资料、合同台账与到期提醒；"附件"统一管理单据扫描件。

> 📷 截图占位：库存列表中红色低库存预警行。

⚠️ 注意：单据一旦审核再修改需要走红冲/反审核流程，不要直接删除历史单据。

## 10. 定额管理

**菜单路径**：**定额管理 → （定额配置 / 定额监测 / 定额分析）**

## 11. 充电站

**菜单路径**：**充电站 → （充电站 / 充电桩 / 商户 / 品牌与型号 / 实时订单 / 历史订单 / 异常订单 / 价格策略 / 运营仪表盘）**

### 11.2 订单处理

1. **实时订单**：查看正在充电的订单（桩、枪、用户、开始时间、实时电量/金额）。
2. **历史订单**：按时间、站点、商户查询已完成订单，用于对账与导出。

### 11.3 价格策略与运营仪表盘

1. **价格策略**：新增策略，设置尖峰平谷各时段单价、服务费、商户适用范围与生效时间；保存发布后订单按新策略计费（**改价务必核对生效时间，避免计费纠纷**）。
2. **运营仪表盘**：一屏看充电量、收入、订单数、利用率、桩在线率、异常率与排行，支持按站点/商户/时间筛选。

## 16. 医院专题

医院模块在通用 EMS 之上叠加"医院智慧能源决策系统"，数据按院区隔离，重点管好 CT、MRI、DR、超声、检验流水线、DSA 等检查检验设备的能耗与能效。

### 16.1 医院大屏读图指南

**入口**：浏览器直接访问路由 `/hospital/screen`，或菜单进入"医院大屏"。建议用大屏/电视墙以全屏展示（按 F11）。

> 📷 截图占位：医院大屏完整截图并分区编号。

| 区域 | 看什么 | 怎么读 |
| --- | --- | --- |
| 顶部标题栏 | 当前院区、日期时间、天气（部分项目） | 先确认院区是否正确 |
| 全院能耗区 | 全院当日/当月电水气总量、费用、同比环比 | 同比箭头红色且非业务量增长原因 → 需要关注 |
| 关键指标区 | 单位面积能耗、单位检查量能耗、待机占比、设备在线率 | 横向对比历史，纵向对比标杆 |
| 检查检验设备状态区 | CT/MRI/DR/超声/检验流水线/DSA 台账卡片 | 颜色：运行/待机/故障/离线；卡片显示实时功率与累计电量 |
| 报警区 | 最新报警滚动 | 红色紧急项必须能马上说出处置进展 |
| 能效排名区 | 设备单位工作量能耗、待机占比排名 | 排名靠后（能耗高）的设备是节能候选 |
| 节能建议区 | 系统生成的节能建议卡片 | 月度会逐条讨论采纳/不采纳 |

**读图三步法**：① 确认院区 → ② 看红色（报警/超标/高排名）→ ③ 点卡片下钻问"为什么、怎么办"。

### 16.2 检查检验设备台账与实时监测

1. **台账**：菜单进入检查检验设备台账，按设备类别（CT/MRI/DR/超声/检验流水线/DSA）查看设备名称、所在科室/房间、额定参数、投运日期、绑定的 IOT 采集点。
2. **实时监测**：进入实时监测页面（或在大屏点设备卡片），查看：
   - 状态：**在线 / 运行 / 待机 / 故障**；
   - 实时功率、当日累计电量、**待机能耗**与待机时长；
   - 功率曲线（运行段与待机段一目了然）。
3. 状态长时间与实际不符（例如设备在做检查却显示待机），联系 IOT 运维核查采集点绑定与判定阈值。

### 16.3 设备工作量、能效排名与节能决策

**菜单路径**：医院模块 → 工作量与能效（菜单名以实际配置为准）

1. 选择院区与月份，页面展示每台检查检验设备的：检查工作量（例数/部位数，来自 HIS/人工录入对接）、总电量、**单位工作量能耗**、待机能耗占比、能效排名。
2. 节能建议使用方法（决策层/能源负责人）：
   1. 筛出"待机占比高"的设备 → 核实是否存在非工作时段未断电/未进节能模式 → 立行立改；
   2. 筛出"单位工作量能耗高"的同类设备 → 对比操作流程与开机时长 → 优化排班、集中检查；
   3. 将建议卡片在月度能源会上分派责任科室，下月用同一张表验证改善幅度。
3. 能耗分析明细、历史趋势与通用"能耗分析"模块口径一致。

### 16.4 院区切换与数据隔离

1. 页面顶部（或大屏右上角）有院区选择器：总院/分院/院区 A/B……
2. 切换后**所有数据、报警、排名只显示所选院区**；你的账号若只授权了一个院区，则看不到其他院区数据，这是正常的数据隔离，不是系统故障。
3. 需要跨院区权限时向管理员申请。

### 16.5 医院报警处理

医院报警规则除通用越限外，还包括检查检验设备的**待机超时、待机功率异常、非工作时段运行、离线**等规则。

处理路径与第 7 章一致（**报警管理 → 实时报警**），特别注意：

1. 正在做检查的设备不要远程断电，先电话确认科室。
2. 涉及临床安全的报警以临床侧意见为先，能源系统侧只做监测与协同。
3. 误报频繁的规则提交能源负责人/管理员调整，不要个人静默报警。
4. 回调数据异常导致的报警，转 IOT 运维查"回调日志监控"。

### 16.6 IOT 设备绑定（业务视角）

业务人员负责确认"系统里的设备"与"现场真实设备/IOT 平台设备"一一对应；绑定技术操作由 IOT 运维完成（见管理员手册第 6 章）。发现张冠李戴（A 设备显示 B 的数据）立即报障，错误数据期间不纳入考核。

## 17. 移动端 APP 使用

移动端基于 uni-app，用于巡检、物品、设备、报警等现场作业，手机上完成"接单—到场—处理—回填"闭环。

### 17.1 登录

1. 打开 APP，输入与 PC 端相同的用户名密码（服务器地址由管理员预置，海外项目注意切换到对应环境）。
2. 首次登录允许"通知/相机/定位"权限——**三项都要允许**，否则收不到任务推送、无法拍照打卡。
3. 底部通常有四个页签：**首页（任务）、消息、应用、我的**。

> 📷 截图占位：APP 登录页与首页待办列表。

### 17.2 巡检任务

1. 在"首页/待办"看到分配给自己的巡检任务，显示任务名、截止时间、点数。
2. 点任务进入，按列表顺序走到巡检点：
   - 点【扫码/NFC】扫现场点位牌（或到达定位范围内点【打卡】）；
   - 按巡检项填写读数/选择"正常/异常"；
   - 点【拍照】现场拍照（支持多张）；
   - 异常项填写异常说明，可直接【转工单】。
3. 全部点完成后点【提交】，任务变为已完成；漏点、超距、超时都会被记录。

### 17.3 维修工单与报警

1. "消息"或工单列表收到派单推送 → 打开工单 →【接单】。
2. 到场后点【到场打卡】（记录位置与时间）。
3. 处理中填写故障原因、维修措施、备件消耗，拍照（故障点/更换件/恢复后各一张）。
4. 完成后点【完工提交】，等待验收；被退回的工单在列表有标记，需重新处理。
5. 报警推送可直接点开查看详情并跳转到关联工单。

### 17.4 物品与设备现场操作

1. **物品**：在"应用 → 物品"中可扫物料条码做现场出库/盘点、查看库存与危化品信息。
2. **设备**：扫设备二维码可直接打开设备档案、实时数据与历史报警。

### 17.5 消息与"我的"

1. **消息**：任务、派单、报警、公告通知汇总，未读有红点。
2. **我的**：查看个人资料、修改密码、切换语言、清理缓存、查看 APP 版本、退出登录。
3. 收不到推送时：检查手机系统通知权限、省电策略是否杀后台，并在"我的"里确认通知开关。

> 📷 截图占位：巡检打卡、拍照上传、工单完工三个关键界面。

## 18. 常见问题 FAQ

**登录与打开类**

**Q1：浏览器输入地址打不开系统？**
A：先确认地址有没有输错、是不是用了 IE；换 Chrome/Edge 试；再确认网络是否在院内网/VPN 内；仍打不开联系信息科查服务与 Nginx。

**Q2：登录提示"用户名或密码错误"？**
A：注意大小写、中文输入法和多余空格；初始密码首次登录必须改；连续输错锁定后等锁定超时或找管理员重置。

**Q3：登录后白屏或一直转圈？**
A：按 Ctrl+F5 强制刷新；清除浏览器缓存；确认浏览器版本 ≥114；参考《前端测试指导》排查；仍异常联系管理员查后端服务（context-path 为 `/autoee-iot-ems`）。

**Q4：数据看板不刷新/数字不动？**
A：看板有刷新周期，可手动点页签刷新按钮或 F5；若长时间不动，先看设备是否在线——可能是采集链路（MQTT/回调）中断，报 IOT 运维查回调日志。

**权限类**

**Q5：同事有的菜单我没有？**
A：菜单由角色授权决定。向系统管理员提交账号申请/权限变更单，不要借用他人账号。

**Q6：菜单能看到，但按钮（新增/删除/导出）是灰的或不显示？**
A：按钮级权限未授权，走权限申请；这是最小权限设计，不是故障。

**Q7：我看不到其他院区/科室的数据？**
A：系统有数据权限（全部/本部门及以下/本部门/仅本人）与院区隔离。确因工作需要，申请扩大数据范围。

**Q8：别人电脑上能看到的菜单，我电脑上看不到？**
A：同一账号权限相同，多为缓存问题，退出重新登录或清缓存；仍不一致让管理员查账号是否用错。

**操作类**

**Q9：导出 Excel 没反应？**
A：看浏览器地址栏是否拦截了弹窗，选择"始终允许弹出"；数据量过大时缩小时间范围分批导；没有【导出】按钮就是没有权限。

**Q10：Excel 导入失败怎么办？**
A：必须用系统下载的最新模板；不要改表头、不要合并单元格；字典列按提示文字填；下载失败错误报告，按行号原因修改后重导。

**Q11：删除的记录能恢复吗？**
A：系统多为逻辑删除，需管理员后台处理，周期长、不一定能恢复。业务单据请优先用"停用/作废/反审核"，删除前务必确认。

**Q12：选错时间范围，图表能快速回到今天吗？**
A：点查询区【重置】后重新选；图表双击可复位缩放；首页快捷时间直接点"今天/本月"。

**Q13：表格列太多/想调整显示顺序？**
A：部分列表右上角有齿轮（列设置）图标，可勾选显示列并拖动顺序，设置按浏览器记住。

**Q14：提交表单提示"系统内部错误"？**
A：多为必填项缺失、格式不对（日期、数字、小数位）或编码重复；按红字提示改；仍报错截图（含页面与时间）发管理员查后台日志。

**数据类**

**Q15：某设备一直没有数据？**
A：按顺序查：设备编码是否正确 → 设备是否绑定网关/IOT 点 → 网关是否在线（最后心跳）→ 让 IOT 运维查 MQTT 与回调日志、签名与 IP 白名单。

**Q16：两台设备数据对调/张冠李戴？**
A：采集点映射绑错，立即报 IOT 运维纠正，错误期间数据不用于考核。

**Q17：总表和分表之和差很多？**
A：先看是否有分表离线/故障/漏装，再看损耗分析；计量问题检查表计检定是否超期/不合格。

**Q18：报警一直响但现场正常，是误报吗？**
A：先看实时值与阈值差多少，可能阈值设置不合理或采集抖动；不要自行关闭，提交规则调整申请给能源负责人/管理员。

**Q19：报警没有收到邮件/消息？**
A：确认个人中心邮箱/手机号正确；确认规则中通知人包含你、值班排班正确；邮件可能在垃圾箱；仍无通知让管理员查邮件服务与通知开关。

**Q20：医院大屏在自己电脑上打不开/变形？**
A：大屏路由 `/hospital/screen`，建议 Chrome 全屏 F11、1920×1080；确认账号有医院模块菜单权限；低分辨率笔记本会自适应压缩，建议接显示器。

**语言与界面类**

**Q21：切换成英文后，有些数据还是中文？**
A：语言切换只翻译系统界面，已录入的业务数据（设备名、科室名、单据内容）保持原文；涉外场景建议台账建档时维护英文名（如系统支持）。

**Q22：不小心切成外文看不懂，怎么切回中文？**
A：右上角地球图标，选最上方/带"中文"字样的选项即可。

**账号与安全类**

**Q23：密码有什么要求？多久改一次？**
A：通常不少于 8 位且含字母+数字，不能与用户名相同；建议 90 天更换，不要多系统共用同一密码。

**Q24：账号可以借给同事用吗？**
A：不可以。所有操作日志实名记录，借账号造成的数据问题由账号本人承担；同事需要权限请单独申请。

**Q25：登录提示账号被停用/锁定？**
A：锁定一般等超时自动恢复；停用是管理员操作（如离岗），需联系管理员核实处理。

**移动端类**

**Q26：APP 收不到任务/报警推送？**
A：检查三项：登录是否被登出、手机通知权限、省电/后台管理是否允许 APP 运行；安卓各品牌均需把 APP 设为"允许后台运行/自启动"。

**Q27：巡检打卡提示"不在巡检点范围内"？**
A：走到点位牌旁打开手机定位与蓝牙；室外检查 GPS，室内依赖扫码/NFC 时直接扫码；确有点位坐标错误报管理员修正。

**Q28：拍照上传一直转圈？**
A：切换院内 Wi-Fi/4G 试；照片会自动压缩，仍失败可在有网络后从待上传队列重发；不要在提交前杀 APP。

**报表与其他**

**Q29：报表数字和图表数字对不上？**
A：先核对时间范围、院区、统计口径（时区、粒度）是否一致；费用报表还受电价策略版本影响；仍不一致截图两个页面时间与条件报管理员核查。

**Q30：视频打不开/黑屏？**
A：看摄像头是否在线；网络是否能访问视频服务器；浏览器是否允许混合内容/插件；多画面打不开先试单画面；持续黑屏报运维查摄像头与流媒体服务。

**Q31：停电/断网恢复后要做什么？**
A：网关恢复后数据会自动续传，关注设备是否恢复在线、曲线是否回填；核对停电时段报警是否为误报；有异常联系 IOT 运维。
