# 系统集成模块用户手册

## 1. 系统概述

系统集成模块是钢铁厂智能能源和碳管理平台的核心组件，负责与外部系统（MES、ERP、环保、消防）进行数据集成和同步。该模块提供了统一的配置管理、任务调度、监控告警和安全审计功能，确保各系统间的数据能够实时、准确地同步。

### 1.1 主要功能
- **系统配置管理**：配置外部系统的连接参数
- **同步任务管理**：创建和管理数据同步任务
- **模板管理**：创建和管理同步模板
- **监控告警**：监控系统运行状态和同步过程
- **安全审计**：记录系统操作和同步过程

### 1.2 适用对象
- **系统管理员**：负责系统配置和维护
- **业务人员**：使用系统进行数据同步和监控
- **技术人员**：进行系统集成和故障排查

## 2. 操作流程

### 2.1 系统配置流程

1. **登录系统**
   - 打开浏览器，输入系统地址
   - 输入用户名和密码
   - 点击登录

2. **进入系统集成模块**
   - 在左侧菜单中点击「系统管理」
   - 选择「系统集成」子菜单

3. **配置外部系统**
   - 点击「配置管理」
   - 点击「新增」按钮
   - 填写系统配置信息
   - 点击「确定」保存

4. **验证连接**
   - 选择已配置的系统
   - 点击「测试连接」按钮
   - 查看连接结果

### 2.2 同步任务管理流程

1. **创建同步任务**
   - 点击「任务管理」
   - 点击「新增」按钮
   - 填写任务基本信息
   - 配置同步参数
   - 点击「确定」保存

2. **执行同步任务**
   - 选择要执行的任务
   - 点击「执行」按钮
   - 查看执行结果

3. **配置定时任务**
   - 编辑同步任务
   - 设置执行频率
   - 保存配置

### 2.3 模板管理流程

1. **创建模板**
   - 点击「模板管理」
   - 点击「新增」按钮
   - 填写模板信息
   - 配置字段映射和转换规则
   - 点击「确定」保存

2. **复制模板**
   - 选择要复制的模板
   - 点击「复制」按钮
   - 输入新模板名称和编码
   - 点击「确定」完成复制

3. **应用模板**
   - 创建同步任务时选择模板
   - 系统自动填充模板配置
   - 调整参数后保存

### 2.4 监控告警流程

1. **查看告警列表**
   - 点击「监控告警」
   - 查看告警信息
   - 按条件筛选告警

2. **处理告警**
   - 选择未处理的告警
   - 点击「处理」按钮
   - 填写处理结果
   - 点击「确定」完成处理

3. **系统健康检查**
   - 点击「健康检查」按钮
   - 查看系统健康状态
   - 处理发现的问题

## 3. 功能说明

### 3.1 系统配置管理

#### 3.1.1 配置项说明
- **系统编码**：外部系统的唯一标识，如MES、ERP、ENV、FIRE
- **系统名称**：外部系统的名称
- **连接URL**：外部系统的API地址
- **用户名**：访问外部系统的用户名
- **密码**：访问外部系统的密码
- **API密钥**：访问外部系统的API密钥
- **超时时间**：连接超时时间（毫秒）
- **状态**：系统配置的状态（启用/禁用）

#### 3.1.2 操作说明
- **新增**：添加新的系统配置
- **编辑**：修改现有系统配置
- **删除**：删除系统配置
- **启用/禁用**：切换系统配置的状态
- **测试连接**：测试与外部系统的连接

### 3.2 同步任务管理

#### 3.2.1 任务配置
- **任务名称**：同步任务的名称
- **任务编码**：同步任务的唯一标识
- **任务类型**：任务的类型，如MES生产计划、ERP采购订单等
- **源系统**：数据来源系统
- **目标系统**：数据目标系统
- **同步类型**：全量同步或增量同步
- **同步频率**：任务执行的频率
- **Cron表达式**：定时执行的表达式
- **字段映射**：源系统和目标系统字段的映射关系
- **转换规则**：数据转换的规则

#### 3.2.2 任务操作
- **执行**：立即执行同步任务
- **编辑**：修改任务配置
- **删除**：删除同步任务
- **启用/禁用**：切换任务的状态
- **查看执行记录**：查看任务的执行历史

### 3.3 模板管理

#### 3.3.1 模板配置
- **模板名称**：模板的名称
- **模板编码**：模板的唯一标识
- **模板类型**：模板的类型，如MES同步、ERP同步等
- **源系统**：数据来源系统
- **目标系统**：数据目标系统
- **字段映射**：源系统和目标系统字段的映射关系
- **转换规则**：数据转换的规则

#### 3.3.2 模板操作
- **新增**：创建新的模板
- **编辑**：修改现有模板
- **删除**：删除模板

### 3.4 监控告警

#### 3.4.1 告警信息
- **告警级别**：告警的严重程度（信息、警告、错误、严重）
- **告警类型**：告警的类型（系统集成、系统健康、数据同步）

## 4. 常见问题

### 4.1 连接问题

#### 4.1.1 无法连接到外部系统
- **问题现象**：测试连接时显示连接失败
- **可能原因**：
  - 网络连接问题
  - 外部系统地址错误
  - 用户名或密码错误
  - 外部系统服务未启动
- **解决方案**：
  - 检查网络连接
  - 验证外部系统地址
  - 确认用户名和密码
  - 检查外部系统服务状态

#### 4.1.2 连接超时
- **问题现象**：连接外部系统时超时
- **可能原因**：
  - 网络延迟
  - 外部系统响应慢
  - 超时时间设置过短
- **解决方案**：
  - 检查网络状况
  - 联系外部系统管理员
  - 增加超时时间设置

### 4.2 同步问题

#### 4.2.1 同步任务执行失败
- **问题现象**：同步任务执行后显示失败
- **可能原因**：
  - 外部系统返回错误
  - 数据格式不匹配
  - 字段映射错误
  - 权限不足
- **解决方案**：
  - 查看执行日志
  - 检查外部系统状态
  - 验证字段映射
  - 确认权限设置

#### 4.2.2 同步数据不完整
- **问题现象**：同步后数据缺失或不完整
- **可能原因**：
  - 外部系统数据不完整
  - 同步条件设置错误
  - 网络中断
  - 超时设置过短
- **解决方案**：
  - 检查外部系统数据
  - 验证同步条件
  - 检查网络连接
  - 调整超时设置

### 4.3 系统问题

#### 4.3.1 系统响应慢
- **问题现象**：系统操作响应时间长
- **可能原因**：
  - 服务器负载高
  - 数据库性能问题
  - 网络延迟
  - 同步任务过多
- **解决方案**：
  - 检查服务器资源使用情况
  - 优化数据库性能
  - 检查网络状况
  - 调整同步任务频率

#### 4.3.2 系统登录失败
- **问题现象**：无法登录系统
- **可能原因**：
  - 用户名或密码错误
  - 账号被锁定
  - 系统服务未启动
  - 网络连接问题
- **解决方案**：
  - 验证用户名和密码
  - 联系系统管理员
  - 检查系统服务状态
  - 检查网络连接

### 4.4 其他问题

#### 4.4.1 权限不足
- **问题现象**：操作时提示权限不足
- **可能原因**：
  - 账号权限不够
  - 角色权限设置错误
- **解决方案**：
  - 联系系统管理员
  - 检查角色权限设置

#### 4.4.2 数据备份
- **问题现象**：需要备份系统数据
- **解决方案**：
  - 使用系统提供的备份功能
  - 定期导出数据
  - 配置自动备份计划

## 5. 故障排查

### 5.1 日志查看
- **系统日志**：查看Tomcat日志目录下的catalina.out文件
- **应用日志**：查看应用日志目录下的日志文件
- **数据库日志**：查看MySQL日志

### 5.2 常见错误代码

| 错误代码 | 错误描述 | 可能原因 | 解决方案 |
|---------|---------|---------|---------|
| 400 | 请求参数错误 | 参数格式不正确 | 检查请求参数 |
| 401 | 未授权 | 未登录或权限不足 | 登录系统或联系管理员 |
| 403 | 禁止访问 | 没有操作权限 | 联系管理员分配权限 |
| 404 | 资源不存在 | 请求的资源不存在 | 检查请求地址 |
| 500 | 服务器内部错误 | 系统代码错误 | 查看日志并联系技术人员 |
| 502 | 网关错误 | 网络连接问题 | 检查网络连接 |
| 503 | 服务不可用 | 系统服务未启动 | 启动系统服务 |
| 504 | 网关超时 | 外部系统响应超时 | 检查外部系统状态 |
