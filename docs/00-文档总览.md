## 一、文档体系说明

本套文档面向智慧能源管理平台（含在原通用 EMS 上**加性叠加**的"医院智慧能源决策系统"）的完整交付过程，覆盖需求工程、架构与详细设计、编码实现、测试验证、部署实施、培训推广六大阶段。各阶段文档之间通过**需求编号（FR）、设计要素、测试用例（TC）** 建立前后追溯关系，可配合 [01需求/01-03 需求跟踪矩阵.md](01需求/01-03%20需求跟踪矩阵.md) 进行全链路追踪。

文档编号规则：`阶段号-序号 文档名称`，例如 `02-03 接口设计说明书`。

```
  01 需求 ──► 02 设计 ──► 03 研发 ──► 04 测试 ──► 05 部署 ──► 06 培训
   (做什么)    (怎么做)    (做出来)    (做得对)    (上得去)    (用得好)
     │           │           │           │           │           │
   调研报告    概要设计    环境搭建    测试计划    部署方案    培训计划
   需求规格    数据库设计  编码规范    测试用例    运维手册    用户手册
   跟踪矩阵    接口设计    实现说明    缺陷与报告  上线回滚    管理员手册
```

## 三、关键技术与环境基线

| 类别 | 基线 |
| --- | --- |
| 后端 | JDK 1.8（强制）、Spring Boot 2.7.9、MyBatis-Plus 3.5.3.1、Sa-Token 1.34 + JWT、Undertow |
| 前端 | Vue 2.6 + Element UI + ECharts + vue-i18n（中/英/俄/印尼）；另有 Vue3 演进版、uni-app 移动端 |
| 存储/中间件 | MySQL 8.0.35（库 `autoee_ems`）、Redis 7.2、RabbitMQ 3.12、EMQX 5.3.2、TDengine 3.x（可开关）、XXL-Job |
| 数据接入 | MQTT 直采（EMQX→RabbitMQ→落库/报警）＋ 医院 IOT 平台 HTTP 回调（鉴权→标准化→MQ→落库，失败重试不丢数） |
| 访问入口 | 后端 `http://IP:8088/autoee-iot-ems`；前端开发 9029 / 生产 Nginx；EMQX 控制台 18083；RabbitMQ 控制台 15672 |
| 默认账号 | `admin / 123456`（上线必须改密） |
| 部署方式 | Docker + Docker Compose；生产编排 `docker-compose-54.yml`（只读，不得修改） |

> 详细命令、账号与注意事项以 [05部署/05-01 部署实施方案.md](05部署/05-01%20部署实施方案.md) 与根目录 `AGENTS.md` 为准。
