## 1. 硬件与软件清单

### 1.1 硬件建议

| 项 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 4 核 | 8 核及以上（本地同时跑 5 个中间件容器 + IDEA + Chrome） |
| 内存 | 16 GB | 32 GB（MySQL/Redis/RabbitMQ/EMQX/TDengine 全量容器较吃内存） |
| 磁盘 | 30 GB 可用空间 | 50 GB 以上 SSD，Docker 镜像与数据卷建议放 SSD |
| 网络 | 可访问外网（拉取 Maven/npm/Docker 镜像） | 配置好内网代理或阿里云镜像 |

### 1.2 必装软件

| 软件 | 版本要求 | 说明 |
|---|---|---|
| **JDK** | **JDK 1.8（强制）** | 根 `pom.xml` 中 `java.version=1.8`，编译目标 1.8。**不兼容 JDK 17+ 直接启动**，高版本必须加 `--add-opens` 参数（见 4.6）。推荐 Temurin/Zulu JDK 8u372+ |
| **Maven** | 3.6.3 ~ 3.8.x | 多模块构建；根 pom 已开启并行构建（4 线程） |
| **Git** | 2.30+ | 克隆代码、分支管理 |
| **Node.js** | **推荐 16.x / 18.x LTS** | 前端为 Vue CLI 4 + Vue 2.6.12；如使用 Node 20/22，`dev` 脚本已内置 `--openssl-legacy-provider`，不要自行删除 |
| **Docker Desktop** | 4.20+（含 Compose V2） | 本地运行 MySQL/Redis/RabbitMQ/EMQX/TDengine；Windows 需启用 WSL2 |
| **IntelliJ IDEA** | 2022.2+（Ultimate 推荐） | 安装 Lombok、Maven Helper 插件；Community 版可配合外置数据库工具 |
| **Python** | 3.8+（仅模拟器需要） | 运行 `simulator/` MQTT 设备模拟与压测工具 |
| 数据库客户端 | 任选 | DBeaver / Navicat / IDEA Database 工具 |
| MQTT 客户端 | 任选 | MQTTX、EMQX Dashboard 自带 WebSocket 工具 |

### 1.3 JDK 安装与 JAVA_HOME

1. 安装 JDK 8 后配置环境变量（PowerShell 查看）：

```powershell
java -version
# 期望输出：java version "1.8.0_xxx"
echo $env:JAVA_HOME
# 例：C:\Program Files\Eclipse Adoptium\jdk-8.0.392.8-hotspot
```

2. `JAVA_HOME` 指向 JDK 8 根目录；Path 中加入 `%JAVA_HOME%\bin`。
3. IDEA 中两处都要设置：
   - `File → Project Structure → Project SDK = 1.8`，Language level = 8；
   - `Settings → Build, Execution, Deployment → Build Tools → Maven → Runner → JRE = 1.8`。

### 1.4 Maven 安装与阿里云镜像

Maven `settings.xml`（`%USERPROFILE%\.m2\settings.xml`）建议配置阿里云镜像，避免依赖下载缓慢：

```xml
<settings>
  <mirrors>
    <mirror>
      <id>aliyun-public</id>
      <mirrorOf>*</mirrorOf>
      <name>aliyun public</name>
      <url>https://maven.aliyun.com/repository/public</url>
    </mirror>
  </mirrors>
  <profiles>
    <profile>
      <id>jdk8</id>
      <activation>
        <activeByDefault>true</activeByDefault>
        <jdk>1.8</jdk>
      </activation>
      <properties>
        <maven.compiler.source>1.8</maven.compiler.source>
        <maven.compiler.target>1.8</maven.compiler.target>
        <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
      </properties>
    </profile>
  </profiles>
</settings>
```

> 根 pom 已声明 `maven.aliyun.com/repository/public` 仓库，即使不配置 settings 也能走阿里云，但 settings 镜像对插件下载同样生效，建议配置。

### 1.5 Node.js 安装

推荐使用 nvm-windows 安装 Node 16/18：

```powershell
nvm install 18.20.4
nvm use 18.20.4
node -v   # v18.x
npm -v
```

`zhurong-admin-ui/package.json` 的脚本已内置 `set NODE_OPTIONS=--openssl-legacy-provider`，因此在 Node 17+ 环境下也可直接 `npm run dev`。若直接调用 `vue-cli-service` 报错 `error:0308010C:digital envelope routines::unsupported`，手动执行：

```powershell
$env:NODE_OPTIONS="--openssl-legacy-provider"
```

## 2. 中间件启动（Docker Compose）

### 2.1 两种本地中间件形态（先读！）

本项目本地研发有两种等价形态，**二选一**：

- **形态 A：shared-infra 共享中间件（团队约定，推荐）**
  中间件统一收口在 `D:\code\shared-infra` 工程中启动（容器名 `shared-mysql`、`shared-redis`、`shared-rabbitmq`、`shared-emqx`、`shared-tdengine`），本系统通过 localhost 映射端口连接。后端配置 `zhurong-ems-admin/src/main/resources/application-local.yml` 即按此约定编写。

- **形态 B：本仓库自带 compose**
  在仓库根目录执行 `docker compose up -d`，使用根目录 [docker-compose.yml](../../docker-compose.yml) 拉起 `zhurong-ems-*` 系列容器。

> ⚠️ 账号差异注意：仓库自带 compose 中 RabbitMQ 默认账号是 `guest/guest`、Redis 未显式设置密码，而 `application-local.yml` 期望连接的是 **RabbitMQ `rabbitmq/rabbitmqpassword`、vhost `admin_vhost`、Redis 密码 `difyai123456`（db 13）**。若使用形态 B，需自行在 RabbitMQ 中创建用户与 vhost、给 Redis 加密码，或临时修改 local 配置；**团队统一使用形态 A 时无需任何调整**。

### 2.2 启动命令

```powershell
# 形态 A：进入共享中间件目录（具体以 shared-infra 工程为准）
cd D:\code\shared-infra
docker compose up -d

# 形态 B：使用本仓库 compose
cd D:\code\gitcp\inspur-ems\deep-ems0
docker compose up -d
```

查看容器状态：

```powershell
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"
```

## 3. 数据库初始化

### 3.1 全量业务库（必做）

全量结构与基础数据脚本：[.dev/dumps/ems_full.sql](../../.dev/dumps/ems_full.sql)。该 dump 由 mysqldump 导出，**已包含 `CREATE DATABASE IF NOT EXISTS autoee_ems` 与 `USE autoee_ems`**，无需手工预建库。

方式一：命令行导入

```powershell
# 在仓库根目录
Get-Content .dev\dumps\ems_full.sql -Raw | docker exec -i shared-mysql mysql -uroot -p123456
# 或先拷贝进容器再导入
docker cp .dev/dumps/ems_full.sql shared-mysql:/tmp/ems_full.sql
docker exec shared-mysql sh -c "mysql -uroot -p123456 -h127.0.0.1 < /tmp/ems_full.sql"
```

方式二：DBeaver/Navicat 连接 `localhost:3306`（root/123456），选中数据库连接执行 `ems_full.sql`。

### 3.2 医院智慧能源模块脚本

医院模块为**加性开发**（只新增表，不改动原有表），脚本位于仓库 [数据库脚本/](../../数据库脚本/) 目录：

| 脚本 | 作用 | 目标库 |
|---|---|---|
| `hospital_init.sql` | 医院 9 张核心表：`hospital_device`、`hospital_metric_def`、`hospital_device_data`、`hospital_area`、`hospital_alarm_rule`、`hospital_alarm_record`、`hospital_callback_log`、`hospital_device_workload` 等 | MySQL `autoee_ems` |
| `hospital_menu.sql`、`hospital_menu_m2.sql`、`hospital_menu_m3.sql`、`hospital_menu_m4.sql` | 医院模块菜单与按钮权限标识（按迭代追加，需全部执行） | MySQL `autoee_ems` |
| `hospital_alarm.sql` | 报警相关补充表/数据 | MySQL `autoee_ems` |
| `hospital_seed_demo.sql` | 演示设备/指标/规则种子数据（本地联调推荐导入） | MySQL `autoee_ems` |
| `hospital_role_dashboard.sql` | 医院角色与大屏看板权限 | MySQL `autoee_ems` |
| `hospital_init_tdengine.sql` | TDengine 超表 `hospital_device_data`（仅开启 TD 时需要） | TDengine 库 `energy` |
| `hospital_rename_reserved_words.sql` | 历史保留字字段修正脚本（存量库升级用） | MySQL `autoee_ems` |

```powershell
# 示例：逐个导入医院 MySQL 脚本
docker cp 数据库脚本/hospital_init.sql shared-mysql:/tmp/
docker exec shared-mysql sh -c "mysql -uroot -p123456 autoee_ems < /tmp/hospital_init.sql"
```

其他常用脚本：

- 根库初始化：[数据库脚本/init.sql](../../数据库脚本/init.sql)；
- XXL-Job 调度中心表：[docker/mysql/init_xxl_job_tables.sql](../../docker/mysql/init_xxl_job_tables.sql)、`docker/mysql/tables_xxl_job.sql`，目标库 `xxl_job`（仅联调定时任务调度中心时需要）；
- `fix_charging_pile.sql`、`fix_sys_menu_encoding.sql` 等为历史数据修复脚本，全新库不需要执行。

### 3.3 TDengine 初始化（默认跳过）

本地默认不启用 TDengine，本节可跳过。需要时序库时：

1. 启动参数去掉 `--spring.datasource.dynamic.datasource.td.enabled=false`（或置 true）；
2. 在 `energy` 库执行 [数据库脚本/hospital_init_tdengine.sql](../../数据库脚本/hospital_init_tdengine.sql)，创建超表：

```sql
CREATE STABLE IF NOT EXISTS hospital_device_data (
    ts TIMESTAMP, metric_value DOUBLE, quality INT
) TAGS (device_code NCHAR(64), metric_code NCHAR(64));
```

> TDengine 3.3.x 注意：强制密码复杂度（需大小写+数字/特殊字符）、不支持 `CREATE USER IF NOT EXISTS`；不要用 `TAOS_ROOT_PASSWORD` 覆盖 root 口令、不要自定义 `command` 覆盖镜像自带 entrypoint，否则会初始化崩溃循环重启。详见 [EMS接入共享中间件本地研发联调经验.md](../部署指南/EMS接入共享中间件本地研发联调经验.md)。

### 4.5 IDEA 启动配置（推荐方式）

1. 用 IDEA 打开仓库根目录（识别根 pom 后自动导入全部 Maven 模块）；
2. 找到启动类 [cpEmsApplication.java](../../zhurong-ems-admin/src/main/java/com/cpems/cpEmsApplication.java)（包 `com.cpems`，注解 `@SpringBootApplication @EnableAsync @EnableScheduling @ComponentScan(basePackages={"com.cpems","com.ruoyi"})`）；
3. 新建 Application Run Configuration：
   - **Main class**：`com.cpems.cpEmsApplication`；
   - **Active profiles**：`local`；


   - JDK 选 1.8；
4. 启动后控制台出现启动横幅，打印 `Local: http://localhost:8088/autoee-iot-ems`，并出现 `MQTT 连接成功，连接方式：直连` 日志。

### 4.6 高版本 JDK 启动（--add-opens）

如本机只有 JDK 9+（11/17/21）并尝试启动，CGLIB 反射会抛 `InaccessibleObjectException`，表现为全站接口 500。必须在 VM options 中追加以下 **10 项** `--add-opens`：

```
--add-opens java.base/java.lang=ALL-UNNAMED
--add-opens java.base/java.lang.reflect=ALL-UNNAMED
--add-opens java.base/java.math=ALL-UNNAMED
--add-opens java.base/java.util=ALL-UNNAMED
--add-opens java.base/java.util.concurrent=ALL-UNNAMED
--add-opens java.base/java.net=ALL-UNNAMED
--add-opens java.base/java.io=ALL-UNNAMED
--add-opens java.base/java.nio=ALL-UNNAMED
--add-opens java.base/sun.nio.ch=ALL-UNNAMED
--add-opens java.base/sun.security.ssl=ALL-UNNAMED
```

```yaml
  password: "public"

stress_test:
  scenarios:
    light:  {devices: 10,   frequency: 1,  duration: 60,  message_type: "voltage"}
    medium: {devices: 100,  frequency: 5,  duration: 300, message_type: "voltage"}

```

### 6.2 常用命令

Windows 直接双击 [run.bat](../../simulator/run.bat)（自动检测 Python 与依赖），或命令行：

```powershell
# 打包数据（数组）走 electric/all/{clientId}

# 压力测试：light/medium/heavy 三档场景
python main.py stress -s light
```

后端订阅的主题（[TopicType.java](../../zhurong-ems-system/src/main/java/com/ruoyi/system/domain/enums/TopicType.java)）：
`electric/emsCarson`、`electric/all/+`、`electric/voltage`、`electric/current`、`electric/power`、`electric/consumption`、`water/consumption/+`。

## 9. 常见问题 FAQ（高频坑）

### 9.1 所有页面/接口报 500：InaccessibleObjectException

**原因**：使用 JDK 9+ 启动，模块封装禁止 CGLIB 反射访问 `java.lang.ClassLoader` 等。
**解决**：换 JDK 8；或按 4.6 加齐 10 项 `--add-opens`。详见 [打包部署常见问题.md](../部署指南/打包部署常见问题.md)。

### 9.2 特定模块 500：表不存在

**现象**：日志 `Table 'autoee_ems.xxx' doesn't exist`。
**解决**：从 [.dev/dumps/ems_full.sql](../../.dev/dumps/ems_full.sql) 补对应建表 DDL；医院表缺失去 [数据库脚本/](../../数据库脚本/) 执行 `hospital_init.sql` 及对应菜单脚本。

### 9.3 逻辑删除与主键

- 逻辑删除字段固定 `del_flag`：`0`=存在，`2`=删除；实体字段使用 `@TableLogic`，全局配置 `logicDeleteValue=2 / logicNotDeleteValue=0`，查询不要手工拼 `del_flag`；
- 主键统一雪花算法：全局 `id-type: ASSIGN_ID`，实体 `@TableId(value="xxx_id")`，不要在 insert 时手工填主键（子表初始化脚本中 id 需显式给出长整型值）。

### 9.4 Redis 连接报错 / NOAUTH / db 不对

**原因**：共享 Redis **必须带密码** `difyai123456`，应用使用 db `13`。
**解决**：检查 `application-local.yml` 的 `spring.redis.password` 与 `redisson.singleServerConfig.password` 是否一致；命令行连接加 `-a difyai123456 -n 13`。

### 9.5 RabbitMQ 连接 / 通道启动失败

- 确认 vhost `admin_vhost` 已创建，用户 `rabbitmq` 对其有配置/写/读权限；
- 队列由应用启动时自动声明（`RabbitExChangeConfig`、`HospitalRabbitConfig`），但 vhost/用户必须先存在；
- 本地不用消息链路时也不要把 RabbitMQ 停掉，否则监听器容器会持续重连刷错误日志。

### 9.6 TDengine 初始化 / 启动崩溃

TDengine 3.3.x：密码需满足复杂度、不支持 `CREATE USER IF NOT EXISTS`；**不要**用 `TAOS_ROOT_PASSWORD` 覆盖 root、不要自定义 `command` 覆盖镜像 entrypoint。本地默认 `td.enabled=false`，不启用即可规避；排障见 [TDengine 手动初始化操作手册.md](../部署指南/TDengine%20手动初始化操作手册.md) 与共享中间件联调经验文档。

### 9.7 其他高频小问题

| 现象 | 处理 |
|---|---|
| 前端启动报 `digital envelope routines::unsupported` | 使用 Node 16/18，或保留脚本内 `--openssl-legacy-provider` |
| 前端编译卡在某个 .vue 文件 | 多为属性内 mustache（`="{{ }}"`），`rg '="{{' src -g "*.vue"` 排查 |
| `npm install` 慢 | 切淘宝 registry：`npm config set registry https://registry.npmmirror.com` |
| 8088/9029/3306 端口占用 | `netstat -ano | findstr :8088` 找进程，或调整启动端口 |
| MQTT 一直连不上 | 确认 EMQX 容器在跑、Dashboard 能登录；clientId 不要与其他实例重复 |
| 登录后菜单空白 | `sys_menu` 数据未导入全，或当前角色未分配菜单；检查 `/getRouters` 返回 |
| xxl-job 注册失败刷错误日志 | local 已 `xxl.job.enabled=false`；若自定义配置确认不要误开 |
| Maven 编译 Lombok/getter 找不到 | IDEA 安装 Lombok 插件并开启 Annotation Processing；JDK 选 1.8 |
