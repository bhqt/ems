# 新功能模块使用手册

## 1. 集控化功能

### 1.1 功能介绍
集控化功能模块实现了对钢厂各区域设备的集中控制和管理，包括设备管理、区域控制、远程操作和控制日志管理等功能。

### 1.2 技术实现
- **后端**：基于Spring Boot和MyBatis Plus实现，提供RESTful API接口
- **前端**：基于Vue 2.6和Element UI实现，采用组件化开发
- **数据库**：使用MySQL数据库存储设备信息和控制日志

### 1.3 使用说明

#### 1.3.1 设备管理
1. 进入集控化功能模块，默认显示设备管理页面
2. 可以通过搜索框搜索设备
3. 查看设备状态和详细信息
4. 对在线设备进行远程控制

#### 1.3.2 区域控制
1. 点击"区域控制"标签页
2. 可以对水源水区域、中间站区域、高位水池区域和水井区域进行集中控制
3. 点击按钮可以开启或关闭区域控制

#### 1.3.3 远程操作
1. 点击"远程操作"标签页
2. 选择操作类型（启动、停止、重启、调整参数）
3. 选择目标设备
4. 输入操作参数（如果需要）
5. 输入安全验证码
6. 点击"执行远程操作"按钮

#### 1.3.4 控制日志
1. 点击"控制日志"标签页
2. 查看所有控制操作的历史记录
3. 包括操作类型、操作目标、操作人、操作时间、操作结果和备注

### 1.4 权限控制
需要具有`control:device:list`权限才能访问集控化功能模块。

## 2. 计量管理

### 2.1 功能介绍
计量管理模块实现了对计量器具的全生命周期管理，包括计量器具管理、校准计划管理、校准记录管理和校准数据分析等功能。

### 2.2 技术实现
- **后端**：基于Spring Boot和MyBatis Plus实现，提供RESTful API接口
- **前端**：基于Vue 2.6和Element UI实现，采用组件化开发
- **数据库**：使用MySQL数据库存储计量器具信息、校准计划和校准记录

### 2.3 使用说明

#### 2.3.1 计量器具管理
1. 进入计量管理模块，默认显示计量器具管理页面
2. 可以通过搜索框搜索计量器具
3. 查看计量器具的详细信息，包括类型、规格型号、安装位置、状态等
4. 点击"校准"按钮为计量器具创建校准计划

#### 2.3.2 校准计划管理
1. 点击"校准计划管理"标签页
2. 可以按日期范围和状态筛选校准计划
3. 点击"新增校准计划"按钮创建新的校准计划
4. 对状态为"待执行"的计划点击"执行"按钮执行校准

#### 2.3.3 校准记录管理
1. 点击"校准记录管理"标签页
2. 可以按日期范围和计量器具搜索校准记录
3. 查看校准记录的详细信息，包括校准日期、校准结果、校准人、偏差值等
4. 点击"导出记录"按钮导出校准记录

#### 2.3.4 校准数据分析
1. 点击"校准数据分析"标签页
2. 查看校准合格率趋势、偏差值分布和计量器具状态统计等图表

### 2.4 权限控制
需要具有`metering:info:list`权限才能访问计量管理模块。

## 3. 能源管理

### 3.1 功能介绍
能源管理模块实现了对钢厂能源使用的全面管理，包括批次管理、能效标杆管理、能源平衡管理和能源质量管理等功能。

### 3.2 技术实现
- **后端**：基于Spring Boot和MyBatis Plus实现，提供RESTful API接口
- **前端**：基于Vue 2.6和Element UI实现，采用组件化开发
- **数据库**：使用MySQL数据库存储批次记录、标杆标准、能源平衡和能源质量记录

### 3.3 使用说明

#### 3.3.1 批次管理
1. 进入能源管理模块，默认显示批次管理页面
2. 可以按日期范围和产品/批次号搜索批次记录
3. 点击"新增批次记录"按钮创建新的批次记录
4. 对状态为"生产中"的批次点击"计算能耗"按钮计算能耗

#### 3.3.2 能效标杆管理
1. 点击"能效标杆管理"标签页
2. 可以搜索标杆标准
3. 查看标杆标准的详细信息，包括能源类型、标杆值、单位、适用范围等
4. 点击"新增标杆标准"按钮创建新的标杆标准
5. 点击"启用"或"禁用"按钮切换标杆标准的状态

#### 3.3.3 能源平衡管理
1. 点击"能源平衡管理"标签页
2. 选择日期和能源类型
3. 点击"计算能源平衡"按钮计算能源平衡
4. 查看能源平衡的详细信息，包括总供应量、总消耗量、平衡量和平衡率

#### 3.3.4 能源质量管理
1. 点击"能源质量管理"标签页
2. 可以按日期范围和能源类型筛选能源质量记录
3. 查看能源质量记录的详细信息，包括质量指标、标准值、实际值、偏差和状态
4. 点击"新增质量记录"按钮创建新的能源质量记录

### 3.4 权限控制
需要具有`energy:batch:list`权限才能访问能源管理模块。

## 4. 系统集成

### 4.1 API接口
所有新功能模块都提供了完整的RESTful API接口，支持与其他系统集成。

### 4.2 数据同步
系统支持与MES、ERP等系统的数据同步，确保数据的一致性和准确性。

### 4.3 安全措施
- 所有API接口都需要进行权限验证
- 远程操作需要输入安全验证码
- 控制操作会记录详细的操作日志

## 5. 常见问题

### 5.1 集控化功能
- **问题**：无法控制设备
  **解决方案**：检查设备状态是否为"在线"，确保设备网络连接正常

- **问题**：区域控制失败
  **解决方案**：检查区域内设备是否在线，确保网络连接正常

### 5.2 计量管理
- **问题**：校准计划执行失败
  **解决方案**：检查计量器具状态，确保计量器具可正常通信

- **问题**：校准记录导出失败
  **解决方案**：检查网络连接，确保浏览器支持文件下载

### 5.3 能源管理
- **问题**：批次能耗计算失败
  **解决方案**：检查生产数据是否完整，确保相关设备数据可正常采集

- **问题**：能源平衡计算偏差较大
  **解决方案**：检查计量器具校准状态，确保计量数据准确

## 6. 总结

新添加的三个功能模块（集控化功能、计量管理、能源管理）为钢厂智慧能碳管理平台提供了全面的能源管控能力，实现了从设备控制、计量管理到能源分析的全流程管理。通过这些功能，钢厂可以更有效地监控和管理能源使用，提高能源利用效率，降低能源成本，减少碳排放，实现绿色生产。

系统采用了现代化的技术架构，具有良好的可扩展性和可维护性，可以根据钢厂的具体需求进行定制和扩展。同时，系统提供了完整的权限控制和安全措施，确保系统的安全性和可靠性。
