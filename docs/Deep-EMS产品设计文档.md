# Deep-EMS产品设计文档

**文档版本**: V1.0  
**创建日期**: 2026-03-27  
**适用项目**: 钢厂智慧能碳管理平台  
**基础平台**: Deep-EMS（祝融能源管理系统）

---

## 一、产品概述

### 1.1 产品定位

本产品采用"Deep-EMS为主，逐步增强"的策略，以Deep-EMS（99.7%完成度）作为核心基础平台，借鉴MyEMS、cp-ems-ruoyi、Super-ERP-MES等平台的成熟模块设计，构建完整的钢厂智慧能碳管理平台。

### 1.2 产品优势

| 优势类别 | 说明 |
|---------|------|
| **风险低** | 基于Deep-EMS的99.7%完成度，核心模块已完善，基础稳固 |
| **见效快** | 核心模块已实现，可快速交付，缩短项目周期 |
| **成本低** | 充分利用现有代码，减少重复开发，降低开发成本 |
| **可扩展** | 模块化设计，便于后续功能扩展和系统升级 |
| **技术成熟** | Deep-EMS采用主流技术栈（Spring Boot + Vue.js），稳定性高 |

### 1.3 功能目标

1. **核心功能完善**：在Deep-EMS基础上，增强能源监控、能源分析、碳资产管理能力
2. **扩展功能补充**：补充新能源管理（光伏、储能、微电网）、生产管理、质量管理等模块
3. **高级功能开发**：开发调度优化、三维能源孪生工厂、系统集成等高级功能
4. **整体覆盖度提升**：从当前的82%提升至85%以上

## 二、顶层综合设计

### 2.1 设计原则

1. **模块化设计**：各功能模块独立开发、独立部署，降低耦合度
2. **可扩展性**：采用插件化设计，便于后续功能扩展
3. **技术一致性**：保持Spring Boot + Vue.js技术栈，降低技术复杂度
4. **数据统一**：建立统一的数据标准和接口规范，实现数据共享
5. **安全可靠**：完善的权限控制、数据加密、日志审计机制

### 2.4 技术架构

**后端技术栈**
- 基础框架：Spring Boot 2.x
- 持久层：MyBatis Plus + Sa-Token
- 数据库：MySQL 8.0 + Redis 7.2 + TDengine 3.2.2
- 消息队列：RabbitMQ 3.12
- 物联网协议：MQTT（Spring Integration）
- 任务调度：XXL-Job 2.3.1
- 缓存：Redis（会话存储、数据缓存、分布式锁）
- 时序数据库：TDengine（能耗历史数据）

**前端技术栈**
- 前端框架：Vue 2.6.12
- UI组件库：Element UI 2.15.12
- 数据可视化：ECharts 5.4.0
- 路由管理：Vue Router 3.4.9
- 状态管理：Vuex 3.6.0
- HTTP客户端：Axios 0.24.0

**基础设施**
- Web服务器：Nginx
- 容器化：Docker + docker-compose
- 监控：服务器监控、Redis监控
- 日志：操作日志、登录日志、系统日志

### 2.5 数据架构

**数据分层**
- ODS层（原始数据层）：设备原始数据、能源原始数据、碳排放原始数据、运维原始数据
- DWD层（明细数据层）：设备明细数据、能源明细数据、碳排放明细数据、运维明细数据
- DWS层（汇总数据层）：设备汇总数据、能源汇总数据、碳排放汇总数据、运维汇总数据
- ADS层（应用数据层）：能源监控数据、能源分析数据、碳资产管理数据、运维管理数据

**数据流设计**
```
设备数据采集 → ODS层 → DWD层 → DWS层 → ADS层 → 应用服务
                    ↓
               数据清洗
                    ↓
               数据规范化
                    ↓
               数据汇总
```

**数据同步设计**
- 实时同步：使用MQTT实时采集设备数据、使用Kafka/RabbitMQ实时同步数据、实时数据缓存到Redis
- 批量同步：使用定时任务批量同步数据、数据同步日志记录、数据同步异常处理

### 2.6 安全架构

**认证授权**
- 统一认证：基于Sa-Token实现统一认证、Token有效期管理、Token刷新机制
- 权限控制：基于角色的权限控制（RBAC）、基于数据权限的控制、基于按钮权限的控制
- 审计日志：操作日志记录、登录日志记录、API调用日志记录

**数据安全**
- 数据加密：敏感数据加密存储、传输数据加密（HTTPS）、密码加密（BCrypt）
- 数据备份：定期数据库备份、异地备份、备份恢复测试

**接口安全**
- 接口鉴权：接口Token验证、接口签名验证、接口频率限制
- 数据校验：输入数据校验、输出数据脱敏、SQL注入防护

## 三、分模块设计

### 3.1 核心模块

#### 3.1.1 运维管理模块

**功能描述**：负责设备巡检、维修工单、值班管理等运维相关功能。

**子模块**：
- 巡检计划管理：制定巡检计划、分配巡检任务、跟踪巡检进度
- 维修工单管理：创建维修工单、分配维修任务、跟踪维修进度、维修验收
- 值班管理：值班安排、值班记录、值班交接
- 排班管理：排班计划制定、排班调整、排班查询
- 巡检记录管理：巡检记录录入、巡检记录查询、巡检异常处理

**流程**：
1. 制定巡检计划 → 分配巡检任务 → 执行巡检 → 记录巡检结果 → 处理异常
2. 提交维修申请 → 创建维修工单 → 分配维修任务 → 执行维修 → 验收维修结果
3. 制定排班计划 → 安排值班人员 → 记录值班情况 → 值班交接

#### 3.1.2 碳资产管理模块

**功能描述**：负责碳排放计算、碳资产管理、碳排放报告等碳相关功能。

**子模块**：
- 碳排放计算：碳排放数据采集、碳排放因子管理、碳排放计算
- 碳资产管理：碳资产登记、碳资产交易、碳资产查询
- 碳排放报告：碳排放报告生成、碳排放报告查询、碳排放报告导出
- 碳排放因子管理：碳排放因子维护、碳排放因子查询、碳排放因子更新

**流程**：
1. 采集碳排放数据 → 应用碳排放因子 → 计算碳排放 → 生成碳排放报告
2. 登记碳资产 → 记录碳资产交易 → 更新碳资产台账 → 查询碳资产状态

#### 3.1.3 视频监控模块

**功能描述**：负责实时视频监控、摄像头配置管理、录像管理等视频相关功能。

**子模块**：
- 实时视频监控：实时视频查看、视频画面切换、视频画面放大/缩小
- 摄像头配置管理：摄像头添加、摄像头修改、摄像头删除、摄像头分组
- 录像管理：录像查询、录像回放、录像下载、录像删除

**流程**：
1. 配置摄像头 → 实时监控视频 → 录制视频 → 查询/回放录像

#### 3.1.4 数据看板模块

**功能描述**：负责数据看板、首页仪表盘、分析报告等数据展示功能。

**子模块**：
- 数据看板：自定义数据看板、数据看板展示、数据看板分享
- 首页仪表盘：关键指标展示、趋势图表展示、异常告警展示
- 分析报告：报告生成、报告查询、报告导出

**流程**：
1. 配置数据看板 → 展示数据 → 生成分析报告 → 导出报告

### 3.2 增强模块

#### 3.2.1 能源监控模块

**功能描述**：负责实时能源数据采集、多能源类型支持、计量点管理等能源监控功能。

**子模块**：
- 实时能源数据采集：数据采集配置、实时数据展示、数据采集状态监控
- 多能源类型支持：电力、水、蒸汽、天然气等多种能源类型
- 计量点管理：计量点添加、计量点修改、计量点删除、计量点分组
- 虚拟计量点：虚拟计量点创建、虚拟计量点计算公式配置
- 离线计量点：离线数据录入、离线数据导入、离线数据校验
- 数据采集协议：Modbus TCP、MQTT等协议支持

**流程**：
1. 配置计量点 → 采集能源数据 → 实时监控数据 → 处理异常数据

#### 3.2.2 能源分析模块

**功能描述**：负责能耗概况、能耗趋势分析、同比环比分析等能源分析功能。

**子模块**：
- 能耗概况：总能耗展示、单位能耗展示、能耗排名
- 能耗趋势分析：日/周/月/年能耗趋势、能耗预测
- 同比环比分析：同比分析、环比分析、分析图表展示
- 分项能耗分析：按部门/设备/区域的能耗分析
- 能源流向分析：能源流向图、能源损耗分析
- 损耗分析：损耗计算、损耗原因分析、损耗降低建议
- 费用报表：能源费用计算、费用趋势分析、费用对比

**流程**：
1. 采集能源数据 → 数据处理 → 分析能耗趋势 → 生成分析报告

#### 3.2.3 报表分析模块

**功能描述**：负责172个预置报告、自定义报表、报表导出等报表功能。

**子模块**：
- 预置报告：172个行业标准报告模板
- 自定义报表：报表模板设计、报表数据配置、报表预览
- 报表导出：PDF、Excel格式导出
- 报表定时生成：定时任务配置、报表自动生成、报表自动发送

**流程**：
1. 选择报表模板 → 配置报表参数 → 生成报表 → 导出/发送报表

#### 3.2.4 新能源管理模块

**功能描述**：负责光伏管理、储能管理、微电网管理等新能源相关功能。

**子模块**：
- 光伏管理：光伏发电监控、光伏发电预测、光伏发电统计
- 储能管理：储能系统监控、储能充放电管理、储能系统维护
- 微电网管理：微电网运行监控、微电网调度、微电网优化
- 虚拟电厂：虚拟电厂聚合、虚拟电厂调度、虚拟电厂收益分析

**流程**：
1. 监控新能源设备 → 采集新能源数据 → 分析新能源效益 → 优化新能源运行

### 3.3 新增模块

## 七、总结

### 7.1 产品优势

1. **风险低**：基于Deep-EMS的99.7%完成度，核心模块已完善，基础稳固
2. **见效快**：核心模块已实现，可快速交付，缩短项目周期
3. **成本低**：充分利用现有代码，减少重复开发，降低开发成本
4. **可扩展**：模块化设计，便于后续功能扩展和系统升级
5. **技术成熟**：Deep-EMS采用主流技术栈（Spring Boot + Vue.js），稳定性高

### 7.2 关键成功因素

1. **明确需求优先级**：聚焦核心功能，避免需求蔓延
2. **借鉴成熟模块**：充分利用MyEMS、cp-ems-ruoyi、Super-ERP-MES的成熟模块，避免重复造轮子
3. **建立统一的技术标准和接口规范**：确保各模块的兼容性和可集成性
4. **采用迭代开发模式**：快速迭代交付，及时反馈和调整
5. **加强项目管理**：建立项目进度监控机制，及时发现和解决问题

### 7.3 预期效果

| 效果类别 | 当前状态 | 预期目标 | 提升幅度 |
|---------|---------|---------|---------|
| 功能覆盖度 | 60% | 85%+ | +25% |
