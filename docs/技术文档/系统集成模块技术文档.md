# 系统集成模块技术文档

## 1. 系统架构

### 1.1 整体架构
系统集成模块采用分层架构设计，主要包含以下层次：

- **表现层**：前端Vue.js应用，负责用户界面和交互
- **控制层**：Spring MVC控制器，处理HTTP请求
- **服务层**：业务逻辑层，实现核心业务功能
- **适配器层**：负责与外部系统的集成
- **数据层**：数据库访问和数据持久化

### 1.2 核心组件

#### 1.2.1 适配器组件
- **SystemAdapter**：适配器接口，定义了与外部系统交互的标准方法
- **MesAdapter**：MES系统适配器实现
- **ErpAdapter**：ERP系统适配器实现
- **EnvAdapter**：环保系统适配器实现
- **FireAdapter**：消防系统适配器实现
- **AdapterFactory**：适配器工厂，根据系统类型创建相应的适配器

#### 1.2.2 同步引擎
- **SyncEngineService**：同步引擎服务，负责执行同步任务
- **异步处理**：使用`@Async`注解实现异步执行
- **批量处理**：支持批量同步和并行处理
- **定时任务**：使用Spring Scheduling实现定时同步

#### 1.2.3 监控告警
- **MonitorAlertService**：监控告警服务，负责系统健康检查和告警管理
- **HealthCheck**：系统健康状态检查
- **AlertManagement**：告警记录和处理

#### 1.2.4 安全审计
- **SecurityAuditService**：安全审计服务，记录系统操作日志
- **OperationLog**：操作日志记录
- **AccessControl**：访问权限控制

### 1.3 数据流

1. **配置管理**：用户通过前端界面配置系统集成参数
2. **任务调度**：定时任务或手动触发同步任务
3. **数据同步**：适配器获取外部系统数据，转换后存储到本地系统
4. **监控告警**：监控同步过程，发现异常时触发告警
5. **安全审计**：记录所有操作和同步过程

## 2. API接口

### 2.1 系统配置管理

#### 2.1.1 查询系统配置列表
- **接口**：`GET /system/integration/config/list`
- **参数**：
  - `systemCode`：系统编码（可选）
  - `systemName`：系统名称（可选）
  - `status`：状态（可选）
- **返回**：系统配置列表

#### 2.1.2 获取系统配置详情
- **接口**：`GET /system/integration/config/{id}`
- **参数**：
  - `id`：配置ID
- **返回**：系统配置详情

#### 2.1.3 新增系统配置
- **接口**：`POST /system/integration/config`
- **参数**：系统配置信息（JSON）
- **返回**：操作结果

#### 2.1.4 修改系统配置
- **接口**：`PUT /system/integration/config`
- **参数**：系统配置信息（JSON）
- **返回**：操作结果

#### 2.1.5 删除系统配置
- **接口**：`DELETE /system/integration/config/{ids}`
- **参数**：
  - `ids`：配置ID列表
- **返回**：操作结果

### 2.2 同步任务管理

#### 2.2.1 查询同步任务列表
- **接口**：`GET /system/integration/task/list`
- **参数**：
  - `taskName`：任务名称（可选）
  - `taskType`：任务类型（可选）
  - `status`：状态（可选）
- **返回**：同步任务列表

#### 2.2.2 执行同步任务
- **接口**：`POST /system/integration/task/execute/{taskId}`
- **参数**：
  - `taskId`：任务ID
- **返回**：操作结果

#### 2.2.3 启动同步调度器
- **接口**：`POST /system/integration/scheduler/start`
- **返回**：操作结果

#### 2.2.4 停止同步调度器
- **接口**：`POST /system/integration/scheduler/stop`
- **返回**：操作结果

### 2.3 模板管理

- **参数**：

- **参数**：

- **返回**：模板详情

#### 2.3.3 新增模板
- **接口**：`POST /system/integration/template`
- **参数**：模板信息（JSON）
- **返回**：操作结果

#### 2.3.4 修改模板
- **接口**：`PUT /system/integration/template`
- **参数**：模板信息（JSON）
- **返回**：操作结果

#### 2.3.5 删除模板
- **接口**：`DELETE /system/integration/template/{ids}`

### 2.4 监控告警

### 2.5 安全审计

#### 2.5.1 查询审计日志
- **接口**：`GET /system/security/audit/list`
- **参数**：

## 9. 总结

系统集成模块采用现代化的技术架构，实现了与MES、ERP、环保、消防系统的无缝集成。通过适配器模式、异步处理、批量同步等技术，提高了系统的性能和可靠性。同时，完善的监控告警和安全审计机制，确保了系统的稳定运行和数据安全。

该模块为钢铁厂智能能源和碳管理平台提供了强大的系统集成能力，能够实时获取和同步各外部系统的数据，为企业的能源管理和碳减排决策提供了有力支持。
