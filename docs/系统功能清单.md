## 系统概述

祝融能源管理系统（EMS）是一个基于 Ruoyi 框架开发的企业级能源管理系统，采用前后端分离架构，通过 MQTT 协议实时采集设备能耗数据，提供全面的能耗监控、定额管理和运维管理解决方案。

**系统特点：**
- 实时数据采集与监控
- 多维度能耗分析
- 智能报警管理
- 完整的运维管理体系
- 充电桩应用场景支持
- 碳资产管理
- 可视化数据看板

## 权限体系

### 权限架构

系统采用基于 Sa-Token 的权限认证框架，实现了细粒度的权限控制。

**权限类型：**

1. **菜单权限**
   - 控制用户可以访问哪些菜单和页面
   - 通过角色分配菜单权限
   - 支持菜单的显示/隐藏

2. **数据权限**
   - 控制用户可以访问哪些数据范围
   - 支持全部数据、本部门及以下、本部门、仅本人等数据范围
   - 通过角色分配数据权限

3. **按钮权限**
   - 控制用户可以执行哪些操作
   - 支持新增、修改、删除、导出等按钮权限
   - 通过角色分配按钮权限

### 角色管理

系统支持多角色管理，每个用户可以拥有多个角色。

**角色类型：**
- 系统管理员：拥有所有权限
- 部门管理员：拥有部门内权限
- 普通用户：拥有基本权限
- 自定义角色：根据业务需求自定义

### 权限分配

**权限分配流程：**
1. 创建角色
2. 分配菜单权限
3. 分配数据权限
4. 分配按钮权限
5. 将角色分配给用户
