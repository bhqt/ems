### 2. 14个核心功能模块
- **设备管理模块**：设备信息、网关设备、设备定义
- **能耗分析模块**：能耗概况、趋势分析、同比环比、分项分析、能源流向、损耗分析、费用报表
- **报警管理模块**：实时报警、历史报警、报警规则、报警分析
- **运维管理模块**：巡检计划、巡检记录、维修工单、巡检点、巡检路径、巡检任务、值班管理、排班管理、示例报告、巡检报警
- **物品管理模块**：物品信息、库存、入库出库、危化品管理、供应商、附件、合同
- **定额管理模块**：定额配置、定额监测、定额分析
- **充电桩管理模块**：充电站、充电桩、商户、品牌、订单、价格策略、仪表盘
- **碳资产管理模块**：碳资产分析
- **视频监控模块**：实时视频、摄像头配置
- **数据查询模块**：电力参数查询
- **管理体系模块**：标准、规章制度、应急预案、工作流程
- **系统管理模块**：用户、角色、菜单、部门、岗位、字典、参数、通知、OSS、MQTT、RabbitMQ、Logo、拓扑、充电、个人中心、注册
- **系统监控模块**：在线用户、登录日志、操作日志、缓存监控、系统监控、Spring Boot Admin、XXL-Job
- **数据看板模块**：数据看板、首页仪表盘、3D可视化、分析报告
