# 项目介绍

## 项目背景与目标

祝融能源管理系统（EMS）是一个基于 Ruoyi 框架开发的企业级能源管理系统。该系统旨在为企业提供全面的能耗监控、定额管理和运维管理解决方案。

系统通过 MQTT 协议实时采集各类设备的能耗数据，提供数据分析和可视化功能，帮助用户优化能耗使用，提升管理效率，实现能源的精细化管理。

## 系统架构说明

### 架构概述

系统采用前后端分离的架构设计，后端基于 Spring Boot 框架提供 RESTful API 服务，前端使用 Vue.js 框架构建单页应用（SPA）。系统通过消息队列实现异步处理，使用时序数据库存储历史数据，通过 MQTT 协议实现与物联网设备的实时通信。

### 分层架构

#### 前端层
- **技术栈**：Vue 2.6.12 + Element UI 2.15.12 + ECharts 5.4.0
- **构建工具**：Vue CLI 4.4.6
- **功能**：
  - 用户界面展示
  - 数据可视化
  - 用户交互处理
  - API 调用与数据处理
- **部署方式**：静态资源，通过 Nginx 提供服务

#### 后端层
- **技术栈**：Spring Boot 2.7.9 + Java 8
- **Web 容器**：Undertow（替代 Tomcat，提供更好的性能）
- **功能**：
  - RESTful API 提供
  - 业务逻辑处理
  - 数据持久化
  - 权限认证与授权（基于 Sa-Token）
  - 定时任务调度（基于 XXL-Job）
  - 系统监控（Spring Boot Admin）
- **模块划分**：
  - `zhurong-ems-admin`：主应用入口
  - `zhurong-ems-framework`：核心框架模块
  - `zhurong-ems-system`：系统管理模块
  - `zhurong-ems-common`：通用工具模块
  - `zhurong-ems-job`：定时任务模块
  - `zhurong-ems-oss`：对象存储模块
  - `zhurong-ems-sms`：短信服务模块
  - `zhurong-ems-extend`：扩展功能模块

#### 中间件层

**数据库**
- **MySQL 8.0**：关系型数据库，存储业务数据（设备信息、用户信息、配置信息等）
- **TDengine**（可选）：时序数据库，用于存储能耗历史数据（生产环境可选启用）

**缓存**
- **Redis 7.2**：缓存服务，用于会话存储、数据缓存、分布式锁

**消息队列**
- **RabbitMQ 3.12**：消息队列服务，用于异步消息处理、系统解耦

**通信协议**
- **MQTT**：物联网通信协议，用于设备数据采集（作为客户端连接到 MQTT Broker）

#### 数据层
- 业务数据：存储在 MySQL 数据库
- 时序数据：存储在 TDengine 数据库（可选）
- 缓存数据：存储在 Redis
- 文件存储：支持本地存储和对象存储（OSS）

## 典型使用流程

### 1. 系统初始化

1. 部署中间件服务（MySQL、Redis、RabbitMQ）
2. 执行数据库初始化脚本（`数据库脚本/20251015.sql`）
3. 启动后端服务
4. 启动前端服务
5. 访问系统登录页面

### 2. 用户登录

1. 使用系统管理员账号登录（账号密码见 `登录账号密码/` 目录）
2. 首次登录后修改默认密码
3. 配置系统基础参数

### 3. 设备接入

1. 在"设备管理"模块中添加网关设备
2. 配置设备 MQTT 连接参数
3. 添加具体设备到网关
4. 系统通过 MQTT 协议接收设备数据

### 4. 数据监控

1. 在"能耗分析"模块查看实时能耗数据
2. 通过"数据看板"查看可视化图表
3. 在"报警管理"模块配置报警规则
4. 系统自动监控并触发报警

### 5. 运维管理

1. 在"运维管理"模块创建巡检计划
2. 执行巡检任务并记录结果
3. 创建维修工单处理设备故障
4. 查看巡检记录和维修历史

### 6. 系统管理

1. 在"系统管理"模块创建用户账号
2. 配置角色权限
3. 分配菜单权限
4. 查看操作日志和登录日志

## Docker 容器化部署

系统已提供完整的 Docker 容器化配置，支持一键部署。

### 中间件部署

仅部署中间件服务（MySQL、Redis、RabbitMQ）：

```bash
docker-compose up -d
```

### 全量部署

部署中间件 + 后端 + 前端：

```bash
docker-compose -f docker-compose.full.yml up -d
```

详细配置说明请参考各 Dockerfile 和 docker-compose 文件中的注释。
